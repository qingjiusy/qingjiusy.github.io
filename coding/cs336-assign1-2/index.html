CS336 Assignment 1 · 交互式学习笔记本

深层网络里，激活值的尺度会随深度不断漂移，梯度也随之爆炸或消失。归一化就是把每一层的激活拉回一个可控的尺度。这一章聚焦作业里要用的 RMSNorm：它比经典的 LayerNorm 更简单——不减均值、没有 bias，只用均方根 (RMS) 做缩放，再乘一个可学习的 gain。

学习目标
#

  1. 理解为什么要归一化：控制激活尺度、稳定深层梯度。
  2. 说清 LayerNorm vs RMSNorm 的差别（减不减均值、有没有 bias）。
  3. 【重头戏】亲眼看到 fp32 upcast 对数值精度的影响，理解 handout 为什么强制要求它——这也是 test_rmsnorm 最容易丢分的点。
  4. 验证归一化的核心性质：输出的 RMS ≈ 1。
  5. 拿到 RMSNorm 的引导骨架，知道自己在 cs336_basics/ 里要写什么。

学术诚信：本笔记本用 nn.LayerNorm / nn.RMSNorm 等 PyTorch 内置件当"参考教具"，只用来展示行为、性质、几何与数值现象，不包含任何可复制粘贴的 run_rmsnorm 解答。真正的实现表达式全部留白（...）给你自己写。

Part A · 为什么要归一化：激活尺度是逐层"指数漂移"的
#

深层网络是一串线性变换的叠加。一个自然但容易想错的问题是：把很多线性层叠起来，激活的尺度会怎样？直觉常说"会炸"，但真相更精细——取决于每一层的"增益因子"有没有越过 1。

首先明确，RMS是均方根。RMS(x) = sqrt(mean(x^2))。 而标准差std是：std(x) = sqrt(mean((x - mean(x))^2)) 两者很接近，区别主要是： RMS：看数值本身离 0 有多远 标准差：看数值离自己的平均值有多远

对一个 (d, d)、权重元素方差为 $\sigma^2$ 的线性层，它作用在激活上时，对标准差 / RMS 的乘性增益约为：

$$g \approx \sqrt{d}\,\sigma$$

推导：输出分量 $h_i=\sum_{j} W_{ij}x_j$，在权重独立同分布假设下 $\mathrm{Var}(h_i)=\sigma^2\|x\|^2$；$d$ 个分量合起来 $\mathbb{E}\|h\|^2 = d\,\sigma^2\|x\|^2$，开方即得 $g=\sqrt{d}\,\sigma$。

nn.Linear 的默认初始化（kaiming_uniform_(a=√5)）让权重服从 $U(-1/\sqrt{d},\ 1/\sqrt{d})$，方差 $\sigma^2=\tfrac{1}{3d}$，于是

$$g=\sqrt{d}\cdot\tfrac{1}{\sqrt{3d}}=\tfrac{1}{\sqrt{3}}\approx 0.577<1.$$

这不是巧合：fan-in 缩放初始化的目的，就是把每层增益压在 1 附近（略小于 1），让信号既不爆炸也不太快消失。现在若人为把权重乘上系数 c，增益变成 $g=c/\sqrt{3}$，于是存在一个临界系数：

$$ c^*=\sqrt{3}\approx 1.73,\qquad \begin{cases} c<\sqrt{3}\Rightarrow g<1\Rightarrow \text{指数消失}\\[2pt] c=\sqrt{3}\Rightarrow g\approx 1\Rightarrow \text{勉强持平（随机游走）}\\[2pt] c>\sqrt{3}\Rightarrow g>1\Rightarrow \text{指数爆炸} \end{cases} $$

下面用三个不同的 c 把这三种情形一次跑出来，并叠上理论预测 $g^{\text{depth}}$ 做验证；然后在爆炸那一档上每层后接 nn.LayerNorm（内置参考件，只看"效果"不看实现），看尺度是否被摁回 $O(1)$。

depth, d, N = 30, 64, 512
sqrt3 = 3 ** 0.5

torch.manual_seed(0)
x0 = torch.randn(N, d)              # 一批输入，std ≈ 1

def run_stack(scale, layernorm=False):
    # 每次重建相同的基准权重再乘 scale —— 隔离出“只有 scale 变了”这一个变量
    torch.manual_seed(0)
    layers = [nn.Linear(d, d, bias=False) for _ in range(depth)]
    for lin in layers:
        with torch.no_grad():
            lin.weight *= scale
    lns = [nn.LayerNorm(d) for _ in range(depth)] if layernorm else None
    stds, h = [], x0
    for i, lin in enumerate(layers):
        h = lin(h)
        if layernorm:
            h = lns[i](h)
        stds.append(h.std().item())
    return stds

# 围绕临界系数 c* = sqrt(3) 取三档
regimes = [
    ("scale=1.00  gain=0.58 (<1) vanish",   1.0,          "tab:blue"),
    ("scale=1.73  gain=1.00 (=1) marginal", sqrt3,        "tab:orange"),
    ("scale=2.60  gain=1.50 (>1) explode",  1.5 * sqrt3,  "tab:red"),
]

fig, ax = plt.subplots(1, 2, figsize=(12, 4.5))
xs = np.arange(1, depth + 1)
for label, scale, color in regimes:
    stds = run_stack(scale)
    g = scale / sqrt3
    ax[0].plot(xs, stds, marker="o", ms=3, color=color, label=label)
    ax[0].plot(xs, stds[0] * g ** (xs - 1), ls="--", color=color, alpha=0.5)  # theory
ax[0].set_yscale("log")
ax[0].set_title("No norm: per-layer gain = scale/sqrt(3) decides the fate\n"
                "(dashed = theory  std0 * gain^depth)")
ax[0].set_xlabel("layer depth"); ax[0].set_ylabel("activation std (log scale)")
ax[0].legend(fontsize=8, loc="center left"); ax[0].grid(alpha=0.3)

stds_ln = run_stack(1.5 * sqrt3, layernorm=True)   # 在“爆炸”档上加 LayerNorm
ax[1].plot(xs, stds_ln, marker="o", ms=3, color="green")
ax[1].set_title("With LayerNorm (even at scale=2.60):\nstd pinned to O(1)")
ax[1].set_xlabel("layer depth"); ax[1].set_ylabel("activation std")
ax[1].grid(alpha=0.3)
plt.tight_layout(); plt.show()

print(f"critical scale c* = sqrt(3) = {sqrt3:.3f}   (per-layer gain = scale / sqrt(3))")
for label, scale, _ in regimes:
    stds = run_stack(scale)
    print(f"  {label:38s} layer1 std={stds[0]:8.3f} -> layer{depth} std={stds[-1]:.3e}")
print("=> 小于 sqrt(3)：指数消失 | 大于 sqrt(3)：指数爆炸 | 默认 fan-in 初始化恰好落在 gain=0.58，略低于 1。")

🔎 反直觉之处，理清就通透了

  • “线性层叠多了一定爆炸"是想当然。左图三条实线各自紧贴同色虚线（理论 $g^{\text{depth}}$），说明尺度是干净的指数漂移，方向完全由每层增益 $g=\text{scale}/\sqrt{3}$ 有没有过 1 决定。
  • 最容易踩的坑：scale=1.3 时 $g=1.3/\sqrt{3}\approx0.75<1$，其实是衰减而非爆炸——想引爆，系数得超过临界值 $\sqrt{3}\approx1.73$。凭"多叠几层肯定炸"的直觉去调，往往方向都是反的。
  • 临界档 $g=1$ 并不"稳定”：它是随机游走，深层会缓慢无规则漂移（橙线在虚线附近乱晃就是这个原因），靠运气才不炸——所以你不能指望手调初始化恰好卡在 $g=1$。
  • 右图才是重点：哪怕用爆炸档，每层后接归一化就把激活值尺度死死摁在 $O(1)$。归一化把"增益必须≈1"这个脆弱平衡从初始化手里接管过去，这就是它让深层网络稳定可训的根本原因。

Part B · LayerNorm vs RMSNorm
#

两者都沿最后一维（特征维 d_model）归一化，但做法不同：

减均值? 缩放依据 bias? 可学习参数
LayerNorm 是 标准差 std（含均值的方差） 有 gain + bias
RMSNorm 否 均方根 RMS（只看平方均值） 无 只有 gain

RMSNorm 去掉了"减均值"和 bias，仅仅是把每个元素除以整条向量的 RMS，公式更简单、计算更省，而效果在大模型上与 LayerNorm 相当——所以本作业用它。

关键的行为差异：RMSNorm 不减均值。

下面给一个带大均值偏置的输入，用两个内置参考件（都关掉仿射参数）看输出：LayerNorm 会把每行均值压到 ~0，RMSNorm 则保留原有的均值结构。

torch.manual_seed(0)
d = 8
x = torch.randn(4, d) + 5.0          # 故意加一个大的均值偏置 (+5)

# elementwise_affine=False 就是关闭可学习参数，让它只做纯粹的数学归一化。
ln  = nn.LayerNorm(d, elementwise_affine=False)   # 参考件：减均值 + 除 std
rms = nn.RMSNorm(d,  elementwise_affine=False)     # 参考件：只用 RMS 缩放

y_ln, y_rms = ln(x), rms(x)

print("y_ln的形状 :", y_ln.shape)
print("y_rms的形状 :", y_rms.shape)

print("输入每行均值        :", x.mean(dim=-1))
print("LayerNorm 输出行均值 :", y_ln.mean(dim=-1),  " <- 被减成 ~0")
print("RMSNorm  输出行均值 :", y_rms.mean(dim=-1), " <- 未减均值，结构保留")
print()
print("=> LayerNorm: 减均值 + 除标准差 (+bias)")
print("   RMSNorm : 不减均值、无 bias，只用 RMS 缩放 + gain")

Part C · 【重头戏】为什么必须 fp32 upcast
#

RMSNorm 里要算"平方的均值再开方"。作业和很多真实训练用 float16 / bfloat16 存激活来省显存，但低精度下先平方再求均值再开方会明显丢有效数字。handout 因此要求：先把输入 upcast 到 float32 再算，算完再 cast 回原 dtype。

这不是"锦上添花"——test_rmsnorm 的容差是 atol=1e-4，而 fp16 直接算的误差量级恰好会越过这条线。下面这是一个纯数值现象演示（对通用张量算"平方均值再开方"，不是 RMSNorm 前向本身）：拿 float64 当"真值"，对比 fp16 直接算 vs 先 upcast 到 fp32。

torch.manual_seed(0)
d = 4096
x_fp16 = torch.randn(d, dtype=torch.float16) * 20.0   # 一个 float16 向量

# 真值：用 float64 算“平方的均值再开方”
ref  = torch.sqrt((x_fp16.double() ** 2).mean())
# 方案 A：全程留在 fp16 里算
r16  = torch.sqrt((x_fp16 ** 2).mean())
# 方案 B：先 upcast 到 fp32 再算
r32  = torch.sqrt((x_fp16.float() ** 2).mean())

print(f"真值 (fp64)        : {ref.item():.6f}")
print(f"fp16 直接算        : {r16.item():.6f}   绝对误差 {abs(r16.item()-ref.item()):.2e}")
print(f"upcast fp32 再算   : {r32.item():.6f}   绝对误差 {abs(r32.item()-ref.item()):.2e}")
print()
print("注意：fp16 的误差量级已接近甚至超过 test_rmsnorm 的 atol=1e-4。")

真值 (fp64)        : 20.208785
fp16 直接算        : 20.218750   绝对误差 9.97e-03
upcast fp32 再算   : 20.208784   绝对误差 8.46e-07

注意：fp16 的误差量级已接近甚至超过 test_rmsnorm 的 atol=1e-4。

Part D · 归一化的核心性质：输出 RMS ≈ 1
#

不管输入的尺度和偏置多离谱，RMSNorm（gain=1 时）都会把每个位置沿最后一维的 RMS 拉到约 1——这就是"归一化"这个名字的含义。下面用内置 nn.RMSNorm（关掉可学习 gain，等价于 gain=1）当参考件，测量它输出的 RMS 来验证这条性质。

torch.manual_seed(0)
x = torch.randn(4, 12, 64) * 7.0 + 3.0   # 任意尺度(×7)与偏置(+3)
rms_ref = nn.RMSNorm(64, elementwise_affine=False)   # gain=1 的参考件
y = rms_ref(x)

def rms_lastdim(t):
    return torch.sqrt((t ** 2).mean(dim=-1))

rin, rout = rms_lastdim(x), rms_lastdim(y)
print("输入各位置 RMS (前5个) :", rin.flatten()[:5])
print("输出各位置 RMS (前5个) :", rout.flatten()[:5], " <- 都 ≈ 1")
print("输出 RMS 是否全部 ≈ 1  :", torch.allclose(rout, torch.ones_like(rout), atol=1e-3))
print()
print("可学习的 gain 会在这个“RMS≈1”的基础上，逐通道再放缩，让模型自己决定每维的尺度。")

输入各位置 RMS (前5个) : tensor([8.1570, 7.8683, 6.0837, 6.9120, 6.4532])
输出各位置 RMS (前5个) : tensor([1.0000, 1.0000, 1.0000, 1.0000, 1.0000])  <- 都 ≈ 1
输出 RMS 是否全部 ≈ 1  : True

可学习的 gain 会在这个“RMS≈1”的基础上，逐通道再放缩，让模型自己决定每维的尺度。

🔬 拓展实验（自己动手）
#

  1. eps 放在哪？ 试着把 eps 放在开方里面 sqrt(mean_sq + eps) 与放在外面 sqrt(mean_sq) + eps 两种写法，用同一个输入比较输出差异。对照 handout 公式确认哪种是对的——这会直接影响 test_rmsnorm。
  2. dtype round-trip：构造一个 float16 输入，走"upcast→计算→cast 回 fp16"的流程，确认输出 dtype 与输入一致。测试可能会检查你有没有把 dtype 还原回去。
  3. gain 的作用：把 nn.RMSNorm 的 weight 设成一个非全 1 的向量，观察输出的每通道尺度如何被 gain 逐维缩放（提示：先量 gain=1 的输出 RMS，再乘 gain 看变化）。
  4. bfloat16 对比：把 Part C 的 fp16 换成 bfloat16 再跑一遍。bf16 动态范围大但尾数更少，“平方均值"的误差表现和 fp16 有何不同？想想这对 upcast 的必要性说明了什么。

回答
#

  1. 放在开方里面，首先本身 eps（一个极小正数）的存在就是为了避免 mean_sq 为 0 或者接近 0 的时候，RMS 为 0，从而保证数值稳定。假设 eps = 1e-5，如果放在根号里面，当 mean_sq = 0 时，算出来的 RMS 为 sqrt(1e-5) ≈ 0.00316；若放在根号外面，则 RMS 变成了 1e-5，两者相差约 316 倍。虽然当 x = torch.zeros(8) 时，两种写法最后输出都是 0，但是当输入接近 0 而不等于 0 时，x / RMS 去做缩放的话，两者输出的量级会相差很大。所以放在里面不仅可以避免分母为 0，也是为了避免分母在接近 0 时变化过于剧烈，使数值和梯度更加稳定。这也是 handout 和 PyTorch 官方实现采用的写法。
  2. 代码如下
# 构造一个 float16 输入
x = torch.randn(2, 4, dtype=torch.float16)

# 保存原始 dtype
input_dtype = x.dtype

# upcast 到 float32 计算
y = x.to(torch.float32)
mean_sq = y.pow(2).mean(dim=-1, keepdim=True)
y = y / torch.sqrt(mean_sq + 1e-5)

# cast 回原来的 dtype
y = y.to(input_dtype)

# 检查 dtype 是否一致
print(f"Input dtype : {x.dtype}")
print(f"Output dtype: {y.dtype}")
print(x.dtype == y.dtype)    # True

Input dtype : torch.float16
Output dtype: torch.float16
True
  1. 代码如下，注意其中提到的nn.RMSNorm 的 weight 就是 gain。它是一个可学习参数，用来对 RMS 归一化后的每个通道进行逐维缩放，从而让模型学习每个通道更合适的输出尺度。
x = torch.tensor([[1.0, 2.0, 3.0, 4.0]])

# 不使用 gain，得到纯 RMS 归一化结果
rms_no_gain = nn.RMSNorm(4, elementwise_affine=False)
base_output = rms_no_gain(x)

# 使用非全 1 的 gain
rms_with_gain = nn.RMSNorm(4)
rms_with_gain.weight.data = torch.tensor([1.0, 2.0, 0.5, 3.0])

output = rms_with_gain(x)

print("纯归一化结果:", base_output)
print("gain:", rms_with_gain.weight)
print("乘以 gain:", base_output * rms_with_gain.weight)
print("RMSNorm 输出:", output)

下面是给你填的骨架（... 处留白，方法体是 ... 所以能无错执行，但它还没有实现任何东西）。把每个 # step 翻译成一行 PyTorch，注意注释里用问号标出的关键抉择。

要点回顾：

  • gain 形状是 (d_model,)，初始化为全 1（这样训练初期等价于"纯归一化”）。
  • 一定要 fp32 upcast，算完 cast 回原 dtype——这是 test_rmsnorm 最常见的丢分点。
  • 沿最后一维算均方，keepdim=True 才能广播回去（回顾第 00 章的 keepdim）。
class RMSNorm(nn.Module):
    def __init__(self, d_model: int, eps: float = 1e-5):
        super().__init__()
        self.eps = eps
        # step 1: 建一个形状为 (d_model,) 的可学习 gain 参数，初始化为全 1
        self.weight = nn.Parameter(torch.ones(d_model))

    def forward(self, x):
        # step 0: 记住输入原始 dtype（最后要 cast 回去）
        in_dtype = x.dtype

        # step 1: upcast 到 float32 —— 关键！否则 atol=1e-4 处容易翻车
        x = x.to(torch.float32)

        # step 2: 沿最后一维算“均方” (mean of squares)，keepdim=True 以便广播
        mean_sq = x.pow(2).mean(dim=-1, keepdim=True)

        # step 3: 由 mean_sq 得到 rms。问：eps 放在 sqrt 里面还是外面？看 handout 公式
        rms = torch.sqrt(mean_sq + self.eps)

        # step 4: 用 rms 归一化 x，再乘 gain(self.weight, 形状 (d_model,) 会广播到最后一维)
        out = self.weight * (x / rms)
        
        # step 5: 把结果 cast 回 in_dtype 再返回
        return out.to(in_dtype)

小结
#

  • 归一化把每层激活的尺度摁在 O(1)，稳住深层网络的前向与梯度（Part A 亲眼所见）。
  • RMSNorm vs LayerNorm：RMSNorm 不减均值、无 bias，只用均方根缩放 + 可学习 gain——更简单、够用。
  • fp32 upcast 是重头戏：低精度下"平方→均值→开方"会丢有效数字，误差量级会越过 test_rmsnorm 的 atol=1e-4；先 upcast 到 fp32、算完再 cast 回去。
  • 核心性质：gain=1 时输出 RMS ≈ 1；gain 再逐通道缩放。
  • 实现清单：gain (d_model,) 全 1 初始化、eps=1e-5、沿最后一维 keepdim 归约、记住并还原 dtype。
