聚焦：通常指的是使某个 HTML 元素（例如 <input>、<textarea> 或 button）获得焦点（focus），即成为当前用户可以输入或操作的元素。这通常用于提升用户体验，例如：

  • 自动聚焦（Auto Focus）：页面加载时，自动让某个输入框获得焦点，便于用户输入。
  • 手动聚焦（Manual Focus）：用户点击按钮或触发某个事件时，让指定的元素获得焦点。
  • 表单验证：当用户提交表单时，如果某些字段不符合要求，可以让它们获得焦点以提示用户。

react中的重要概念
#

受控表单绑定
#

概念：使用React组件的状态（useState）控制表单的状态

//准备一个React状态值
const [value, setValue] = useState('')

//通过value属性绑定状态，通过onChange属性绑定状态同步的函数
<input
  type="text"
  value={value}
  onChange={(e) => setValue(e.target.value)}
/>

React中获取DOM
#

在React组件中获取/操作DOM，需要使用useRef钩子函数，分为两步：

  1. 使用useRef创建ref对象，并与JSX绑定
const inputRef = useRef(null);

<input type="text" ref={inputRef} />
  1. 在DOM可用时，访问inputRef.current拿到DOM对象
console.log(inputRef.current);

组件通信
#

概念：组件通信就是组件之间的数据传递，根据组件嵌套关系的不同，有不同的通信方法。有父子通信，兄弟通信，跨层通信。

父传子
#

父传子：把父组件中的数据传给子组件来用

实现步骤

  1. 父组件传递数据-在子组件标签上绑定属性
  2. 子组件接收数据-子组件通过props参数接收数据(props是一个对象，包含着父组件传递过来的所有的数据)

有关于props：

  • props可传递任意的数据 数字、字符串、布尔值、数组、对象、函数、JSX
  • props是只读对象 子组件只能读取props中的数据，不能直接进行修改，父组件的数据只能由父组件修改

特殊的prop children

场景：当我们把内容嵌套在子组件标签中时，父组件会自动在名为children的prop属性中接收该内容

子传父
#

核心思路：在子组件中调用父组件中的函数并传递参数

把父组件中的函数传入到子组件后，子组件在某些事件中调用这个函数并传入参数，这样子传父就能实现

兄弟组件通信
#

实现思路：借助状态提升机制，通过父组件进行兄弟组件之间的数据传递

跨层级组件通信
#

使用context机制来实现！

实现步骤：

  1. 使用createContext方法创建一个上下文对象Ctx
  2. 在顶层组件（App）中通过Ctx.Provider组件提供数据
  3. 在底层组件（B）中通过useContext钩子函数获取消费数据

useEffect的概念理解
#

useEffect是一个React Hook函数，用于在React组件中创建不是由事件引起而是由渲染本身引起的操作，比如发送AJAX请求，更改DOM等等。最常见的就是发送网络请求引起的渲染。

useEffect(() => {}, []);

参数1是一个函数，可以把它叫做副作用函数，在函数内部可以放置要执行的操作参数。

2是一个数组（可选参），在数组里放置依赖项，不同依赖项会影响第一个参数函数的执行，当是一个空数组的时候，副作用函数只会在组件渲染完毕之后执行一次。

useEffect的依赖项参数情况
#

useEffect副作用函数的执行时机存在多种情况，根据传入依赖项的不同，会有不同的执行表现。

useEffect 清除副作用
#

在useEffect中编写的由渲染本身引起的对接组件外部的操作，社区也经常把它叫做副作用操作。

什么是副作用？

在 React 组件中，useEffect允许我们执行与组件渲染无关的外部操作，例如：

  • 订阅 WebSocket
  • 设置 setTimeout 或 setInterval
  • 监听浏览器事件（如 window.addEventListener）

这些操作在组件渲染后执行，但如果不加清除机制，可能会导致内存泄漏或重复执行的问题。

useEffect(() => {
  // 实现副作用操作逻辑

  // 返回一个清理函数，组件卸载时执行
  return () => {
    // 清除副作用逻辑
  };
}, []);

自定义hook函数
#

自定义Hook是以use打头的函数，通过自定义Hook函数可以用来实现逻辑的封装和复用。

封装自定义hook通用思路:

  1. 声明一个以use打头的函数
  2. 在函数体内封装可复用的逻辑（只要是可复用的逻辑）
  3. 把组件中用到的状态或者回调return出去(以对象或者数组)
  4. 在哪个组件中要用到这个逻辑，就执行这个函数，解构出来状态和回调进行使用|

ReactHooks使用规则
#

使用规则:

  1. 只能在组件中或者其他自定义Hook函数中调用
  2. 只能在组件的顶层调用，不能嵌套在if、for、其他函数中
