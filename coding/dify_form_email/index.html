什么是Dify？
#

Dify是一个用于构建AI应用程序的开源平台。Dify融合了后端即服务（Backend as Service）和LLMOps理念。它支持多种大型语言模型，如Claude3、OpenAl等，当然也支持最近的大火的deepseek（最实惠的一集）！

并与多个模型供应商合作，确保开发者能根据需求选择最适合的模型。Dify通过提供强大的数据集管理功能、可视化的Prompt编排以及应用运营工具，大大降低了AI应用开发的复杂度。

而具体来说，dify里面可以生成这一系列的ai相关的应用：

而本次主要利用的是agent和workflow。

那么为什么要选择dify呢？

原因就是dify强大的交互能力和可视化界面。我相信一开始使用dify的时候绝对会震惊到你，做的非常完善的可视化界面，可以帮助你快速的了解整个工作的流程和构建你自己的agent。

工作流搭建
#

这次的技术实现目标中，生成google form和发送邮件就是依赖工作流来实现的。如果说agent是一个人，那么workflow就是一个工具。而“人”可以聪明的选择自己在什么时候去使用工具，去完成自己的目标。

Dify 工作流分为两种类型：

  • Chatflow：面向对话类情景，包括客户服务、语义搜索、以及其他需要在构建响应时进行多步逻辑的对话式应用程序。

  • Workflow：面向自动化和批处理情景，适合高质量翻译、数据分析、内容生成、电子邮件自动化等应用程序。

而本次主要是自动化的一系列任务，因此我们选择使用Workflow来搭建两条，一条是将markdown形式/自然语言形式的问卷转变成google form，另一条是自动发送邮件。

google app script相关设置和解释
#

导入工作流，具体的repo在这里。这是一条将进入的markdown内容的问卷转变为一个google form的工作流，并且会根据是否传入email address来决定是否发送邮件，如果发送则去调取发送邮件的工作流。

为了将这个项目实现并部署到本地，导入工作流以外还要做一些工作。首先是在dify中定义你需要的模型，这部分就是获取模型api并导入了，不再赘述。

然后在Google Drive中创建一个文件夹，用于存放生成的google form，在这里，请获得文件夹的id（后面要用），也就是进入文件夹后url中显示的最后一串，也就是下面的XXXXXXXXX部分：

https://drive.google.com/drive/folders/XXXXXXXXX

然后，编写Google Apps Script，这个脚本是能够将传入的符合模式的json数据转变为google form并存入刚刚创建的文件夹。

步骤如下：

首先新建一个脚本文件。

在脚本文件中编写：

function createFormInFolder(formData) {
  // 从脚本属性中获取文件夹 ID
  const folderId = PropertiesService.getScriptProperties().getProperty("FOLDER_ID");
  if (!folderId) {
    throw new Error("文件夹 ID 未设置在脚本属性中。请先执行 setFolderId()");
  }
  // 获取指定的文件夹
  const folder = DriveApp.getFolderById(folderId);

  // 从 JSON 数据中获取标题和描述
  const title = formData.title || "Untitled Form";
  const description = formData.description || "";

  // 创建 Google 表单
  const form = FormApp.create(title).setDescription(description);

  // 获取问题列表
  const questions = Array.isArray(formData.questions) ? formData.questions : [];

  // 添加问题
  questions.forEach(function(q) {
    const questionText = q.question || "No question text";
    const questionType = (q.type || "TEXT").toUpperCase(); // 转换为大写以便更容易判断
    const choices = q.choices || [];

    switch (questionType) {
      case "TEXT":
        form.addTextItem()
          .setTitle(questionText);
        break;

      case "PARAGRAPH":
        form.addParagraphTextItem()
          .setTitle(questionText);
        break;

      case "MULTIPLE_CHOICE":
        form.addMultipleChoiceItem()
          .setTitle(questionText)
          .setChoiceValues(choices);
        break;

      case "CHECKBOX":
        form.addCheckboxItem()
          .setTitle(questionText)
          .setChoiceValues(choices);
        break;

      case "LIST":
        form.addListItem()
          .setTitle(questionText)
          .setChoiceValues(choices);
        break;

      case "LINEAR_SCALE":
        // 处理 LINEAR_SCALE（刻度）的示例
        // 假设以下属性存在：
        //   q.scaleMin, q.scaleMax, q.scaleMinLabel, q.scaleMaxLabel
        // 如果这些属性不存在，则使用默认值进行设置
        const scaleMin = q.scaleMin || 1;
        const scaleMax = q.scaleMax || 5;
        const scaleMinLabel = q.scaleMinLabel || "";
        const scaleMaxLabel = q.scaleMaxLabel || "";

        form.addScaleItem()
          .setTitle(questionText)
          .setBounds(scaleMin, scaleMax)
          .setLabels(scaleMinLabel, scaleMaxLabel);
        break;

      default:
        // 未定义或未知的类型按 TEXT 处理
        form.addTextItem()
          .setTitle(questionText);
        break;
    }
  });

  // 将创建的表单移动到文件夹
  const file = DriveApp.getFileById(form.getId());
  folder.addFile(file);
  // 如果想从根目录（My Drive）中移除，请取消注释
  // DriveApp.removeFile(file);

  return form;
}



function doPost(e) {
  try {
    // 解析 POST 请求中的 JSON 字符串
    const data = JSON.parse(e.postData.contents);

    // 调用 createFormInFolder 函数创建表单
    const form = createFormInFolder(data);

    // 获取表单的提交URL（填写表单的链接）
    const responseUrl = form.getPublishedUrl();
    // 如果这里你想要的是使用者的编辑界面的url，就用下面这段程序，然后去把output那里也改动一下
    // const editUrl = form.getEditUrl();

    // 以 JSON 格式返回响应
    const output = {
      success: true,
      responseUrl: responseUrl
      // editUrl: editUrl
    };
    return ContentService.createTextOutput(JSON.stringify(output))
      .setMimeType(ContentService.MimeType.JSON);

  } catch (error) {
    // 如果发生错误，则以 JSON 格式返回
    const output = {
      success: false,
      message: error.toString()
    };
    return ContentService.createTextOutput(JSON.stringify(output))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
