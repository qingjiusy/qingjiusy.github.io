1. Two Sum
#

题型
#

哈希表查找补数

识别信号
#

需要找出数组中存在的组合，并且要返回数组元素的idx，天生适合哈希表。需要快速判断target - nums[i]是否出现过。

核心思路
#

遍历到 nums[i] 时，只需要检查 target - nums[i] 是否已经在哈希表中；如果在，就找到了两个下标。

易错点
#

其中数组中元素的value可以相同，因此在构造哈希表时要考虑这点，查答案时必须避免使用同一个元素。我使用的方法是哈希表中的key放数组中的value，哈希表中的value放数组value对应idx的最大值。之后找答案的时候数组从idx = 0开始从头遍历，避免重复。

复杂度（可选）
#

时间复杂度 O(N) 空间复杂度 O(N)

49. 字母异位词分组 Group Anagrams
#

题型
#

哈希表分组 + 字符频次签名

识别信号
#

字母异位词就是每个词中出现了相同次数的字母，而字母和出现次数这种对应关系就是一种哈希关系

核心思路
#

我们遍历list中的每个词，统计词中出现的每个字母的个数，因为规定词只由小字母组成，因此我们可以用一个26长度的列表来表示dict的key

实现要点
#

遍历每个词然后统计字母出现个数来构造哈希表。key 相同的字符串放进同一个列表，最后返回哈希表的 values

易错点
#

python中不可以把list当作dict的key（因为dict的key必须是不可变对象），因此我们要把list转变成tuple

复杂度（可选）
#

时间复杂度：O(N(M+K))，其中N是列表长度，M是列表中字符串的最大长度，K是字符集的大小，这题中K=26 因为这个算法中，dict的key是tuple，tuple做key的时候，查询dict的key这个动作的时间复杂度是tuple的长度。

128. 最长连续序列 Longest Consecutive Sequence
#

题型
#

哈希集合

识别信号
#

不要求连续数组中的元素在原数组中连续，只是要求它们能够保持连续，这种情况用哈希集合可以很快去判断某个元素存不存在。

核心思路
#

把数组元素变成哈希集合，减少了重复并且方便查询。对于最长连续序列来说，最开始的数一定是连续序列中最小的数。 因此对于一个数num，我们去判断num-1存不存在，如果存在可以直接不查询它的连续序列长度。 如果不存在num-1，我们再去查找它的连续序列长度。

实现要点
#

只需要利用哈希表中的key，因此直接使用哈希集合set来避免重复。遍历set，只有当 num-1 不存在时才从 num 开始向右扩展，并更新最大长度

易错点
#

注意查询一个num的连续数组的时候，查询的数字是num不断累加1

复杂度（可选）
#

O(N) 遍历一次set的时间复杂度是O(N)，并且对于set中的所有花在连续数组查询的时间总和也不会超过O(N)，因此整体时间复杂度就是O(N)

283. 移动零 Move Zeroes
#

题型
#

双指针

识别信号
#

不能开辟新的内存空间，但是要移动数组元素。非零元素的相对顺序必须保持不变。

核心思路
#

从左到右依次收集非零元素，把它们放到数组前面。因此我们可以利用双指针从左向右移动，其中左侧指针指向下一个非零元素应该放的位置，右侧指针指向目前要处理的元素。

实现要点
#

right指针向右移动，如果出现非0元素则和left指针调换位置。交换后 left++

易错点
#

注意我一开始想的是从右到左去移动为0的元素，但是最后的结果发现非0元素的相对位置变了。所以要注意移动的方法会不会影响相对位置。

复杂度（可选）
#

时间复杂度O(N)

11. 盛最多水的容器 Container With Most Water
#

题型
#

相向双指针

识别信号
#

要找出最大的接水体积。从数组中选两个位置作为左右边界，面积由“宽度 × 较短高度”决定。

核心思路
#

在一开始，双指针指向数组的左右边界，表示数组中所有的位置都可以作为容器的边界。所以双指针要移动肯定是从边界向内移动。 然后要注意，接水体积受较短那条边决定，因此向内移动短边来寻求更长的边来扩大体积（向内移动本身就是在缩小底边）。 移动长边只会让宽度变小，而短板不变或更差，所以不可能得到更优解。

实现要点
#

移动相对较短的边，终止条件是两条边重合，底边为0不可能接水。

易错点
#

注意移动条件，两边相等时我们移动任意一条边。

复杂度（可选）
#

时间复杂度O(N)

15. 三数之和 3Sum
#

题型
#

排序+相向双指针

识别信号
#

要找到「不重复」且和为 0 的三元组，最简单的就是三重循环。但是不重复我们应该联想到排序，排序以后我们遍历数组，假设遍历的是idx，我们剩下的任务就是去找两个数让他们加上idx的数，总和为0。

核心思路
#

不重复引导我们排序，同时排序后我们要去以三数之和为一个标的去找可能的组合。那么我们就可以有两个在端点的指针，如果总数和小了，就移动left指针去增加总和；如果总数和大了，就移动right指针去减小总数和。

实现要点
#

我们遍历排序后的数组，假设现在遍历到idx，left指针应该从idx右边开始，right指针应该从数组末尾开始。 当left大于等于right或者idx的右边剩下不到两个元素了，我们的遍历也就结束了。 同时为了不重复，我们要注意在每一次找到正确答案的时候更新后进行重复性检查。 同时我们对idx也要进行去重。

易错点
#

注意这里的去重很容易做错。 首先明确，去重应该是对找到一组正确答案更新后的参数进行去重，避免更新后的参数和之前的参数一样，被我们再次记录。 只能对刚移动过的指针做去重，不能没移动 left 却因为 left 重复就把它跳过，比如[-1,0,0,1,2,3]。我们如果idx=-1,left=0,right=3，这时候不正确，我们更新参数但是发现left还是0，这时候如果对left去重，让他向右移动，我们就错过了我们的答案。 并且每次找到正确答案更新后的去重是去对对比之前已经有的答案中的参数。比如[-2, 0, 1, 1, 2]，我们找到了[-2, 0, 2]这一组答案以后，如果错误的对未来的元素进行去重分析，我们会认为[1, 1]这一段重复了。然后移动left和right指针，让right < left故而产生错误。

复杂度（可选）
#

O(N^2) idx移动的复杂度是O(N)，对于每个移动好的idx，我们在里面去做双指针移动的复杂度是O(N)。虽然有排序，但是排序复杂度O(NlogN)小于O(N^2)。

42. 接雨水 Trapping Rain Water
#

题型
#

相向双指针 或者 动态规划

识别信号
#

一道经典题，直接记忆。 每个位置能接多少水，取决于它左侧最高墙和右侧最高墙中的较小值。

核心思路
#

以每个长度为1的底（也就是单个元素）作为一个单位，一个个来看每个元素能接的雨水的量。每个单位位置能接的水 = 底边（固定为1）* 接水高度（min（左边所有元素的最高值，右边所有元素的最高值））。移动元素计算出一个个元素对应的左边元素最高值和右边元素最高值这个方法，可以让我们想到用动态规划来解答。 但是在这里我们可以进一步优化，尝试使用双指针来解答。因为可以显然注意到维护左边或者右边元素的最大值这个数组是有点冗余的，我们可以考虑去用双指针＋leftmax和rightmax两个参数来完成这件事。 我们从left，right两个指针中来选择接下来移动哪个位置，如果leftmax < rightmax，我们就可以确定left处的积水量；反之亦然。

为什么呢？ 因为对于此时的left的来说，左边的屏障是已经确定的，一定是leftmax；右边起码是大于等于rightmax，只是没确定一个特定的值。但是现在leftmax < rightmax，所以无论如何left这个位置的水不会从右边流走，left位置的储水量就是leftmax - height[left]

实现要点
#

我们对比leftmax和rightmax，通过大小对比移动哪个位置。如果相同，则移动左边右边都可以。 终止条件是left和right重合了。 每次更新后，不仅更新left或者right，还要去更新对应的leftmax或者rightmax。

易错点
#

要去理解好更新的条件，注意是去对比leftmax和rightmax来决定移动left还是right，而不是去比较left和right。

复杂度（可选）
#

双指针法： 时间复杂度 O(N) 空间复杂度 O(1)

动态规划： 时间复杂度 O(N) 空间复杂度 O(N)

3. 无重复字符的最长字串Longest Substring Without Repeating Characters
#

题型
#

滑动窗口+哈希集合/哈希表 找出最长子串

识别信号
#

连续子串 + 不允许重复字符 + 需要最大长度

核心思路
#

使用滑动窗口，要注意的是left，right这两个指针的初始化以及在两个指针滑动过程中检查条件是否满足。 有一个很好用的思路： 一般来说，一直满足条件，右指针向右滑动，直到出现问题不满足条件；然后左指针向右滑动，直到再次满足条件

在这里，我们就是right遍历，对于这个新加入的right元素，我们先用哈希表去检查现在有没有重复，没有的话可以继续遍历right；有的话则需要尝试移动left来去重。

实现要点
#

有一段比较好用的python伪代码去表示这个滑动窗口代码的框架：

初始化你的ans
left = 0

for right, value in enumerate(s):
    加入s[right]或者进行某种变更

    while(left <= right and 不符合条件):
        变更
        left += 1
    
    ans 进行变更

易错点
#

  1. left，right我们去取闭区间，这两个idx对应的参数都是可取的
  2. 边缘参数的判定我们可以取特殊情况，比如left = right。这样我们在子串的情况下可以方便判断究竟写right - left还是right - left + 1

复杂度（可选）
#

时间复杂度 O(N)

438. 找到字符串中所有字母异位词 Find All Anagrams in a String
#

题型
#

滑动窗口

识别信号
#

寻找异位词子串，所以子串长度固定，适合滑动窗口

核心思路
#

由于字符串由小写字母组成，我们用一个长度为26的数组count来统计我们的窗口中的子串相对于目标序列p多了什么字符，少了什么字符。如果不多不少就证明是异位词，记录即可

实现要点
#

其中count[0] = 1表示字符"a"在窗口子串中的总数量比p多一个，count[1] = -2表示字符"b"在窗口子串中的总数量比p少两个。

239. 滑动窗口最大值 Sliding Window Maximum
#

题型
#

有两种做法，接下来也说明两种。 做法一：优先队列大根堆 + 延迟删除

做法二：单调队列

识别信号
#

做法一： 移动窗口来快速寻找窗口中的最大值，本身就是适合大根堆的特性，寻找最大值特别方便。

做法二： 因为要求出窗口中的最大值并且窗口逐元素移动，可以考虑使用单调队列。

核心思路
#

做法一： 首先实现大根堆，每次要计算窗口中最大值时，就用看大根堆的heap[0]。但是堆虽然找最大值比较好找，删除一个任意元素则要花较长时间。因此我们在堆中存放的不仅是数字，应该是一个元组，是（index位置的数字，index），这样我们在试图提取最大值时，假如此时的右边界是right，窗口左边界就是right-k+1，先去判定一下这个元素还在不在我们的窗口里面，如果不在就直接pop就好，然后继续提取我们的最大值。

做法二： 首先要想明白，对于一个窗口中的index i和j来说，我们假设i < j，如果nums[i] < nums[j]的情况下，只要窗口中的index包含了j，那么起码一定不会去取nums[i]，它是可以直接被丢弃的。从这个角度出发，我们需要维护一个单调递减队列。一旦新加入的元素大于单调队列中的尾部元素，我们就可以直接丢弃尾部元素，因为它绝对不会被使用。 同时我们最后在获取答案时是从单调递减队列的左边（也就是队列的最大值）来找，我们在这个时候去判断这个最左端的元素还在不在我们的窗口内，如果不在了就pop它，继续检查我们单调队列的新的最左端元素。

实现要点
#

做法一： 在python中，堆其实底层是由list实现的，并且只支持小根堆。因此我们使用大根堆时，把元素取负放入小根堆即可。另外对于其中元素是（x，y）元组的堆来说，是根据x来进行堆的构造的。

做法二： 在python，单调队列常常要使用双端队列来完成，因为我们在要两端加入和删除元素，因此使用deque()。 先清理队尾较小元素，再把right入队；窗口形成后，清理过期队头，再记录nums[deque[0]]。

易错点
#

做法一： 首先对于大根堆，构造和取出的时候，元素都要记得取负。另外在窗口的滑动循环中，如果是移动窗口的right指针，要注意每次移动以后先去把right指针位置的元素push进堆，然后在取出堆顶元素判断是不是在窗口中，如果是就加入ans，如果不是就pop掉，继续判断堆顶元素。

做法二： 我们在deque中元素存的是nums中的index，这样我们取deque[0]来判断它在不在我们的窗口中很方便。在每次right指针右移的时候，我们要循环检查目前deque最右端是否比right指针对应的元素大，不大的话则要pop deque的最右端元素来保证我们的deque是单调递减队列。

复杂度（可选）
#

做法一： 时间复杂度 O(NlogN) 因为将一个元素放入优先队列的时间复杂度是O(logN) 空间复杂度 O(N) 因为延迟删除，堆的占用空间就是O(N)

做法二： 时间复杂度 O(N) 空间复杂度 O(K) 因为我们每次移动指针，都会弹出不在窗口中的元素，deque的长度不会超过K

#

注意在根据标记数组来转变矩阵元素，把它变成0的过程中，我们可以依然使用双重循环，从第一行第一列开始的逐元素遍历，这样代码会简洁。 内部元素 matrix[i][j] 置零条件是 matrix[i][0] == 0 or matrix[0][j] == 0。

易错点
#

注意行和列容易搞混，建议用m来固定表示行数，n来表示列数。用i来遍历[0, m)，用j来遍历[0, n)。

复杂度（可选）
#

时间复杂度 O(MN) 其中M是矩阵的行数，N是矩阵的列数。我们至多只需要遍历该矩阵两次。 空间复杂度 O(1) 除了原有矩阵以外，没有开额外新空间。

54. 螺旋矩阵 Spiral Matrix
#

题型
#

矩阵边界收缩遍历

识别信号
#

按照题目中描述的方法，进行遍历。

核心思路
#

在遍历过程中，我们可以维护top，bottom，left，right四个维度参数来指导遍历。遍历的过程是确定的：

  1. [top, left]到[top, right]
  2. [top+1, right]到[bottom, right]
  3. 判断是否left < right且top < bottom，如果是，则：从[bottom, right-1]到[bottom, left+1]，从[bottom, left]到[top+1, left]
  4. 完成一层遍历，更新top，bottom，left，right四个维度参数

实现要点
#

遍历过程中要时刻注意是更新行还是列。 top, bottom, left, right = 0, m - 1, 0, n - 1

易错点
#

注意在遍历的时候，我们要保证top <= bottom且left <= right，并且进行完从左到右和从上到下的更新以后，我们要去判断是否left < right且top < bottom，来避免我们从右到左和从下到上的更新重复读取。

复杂度（可选）
#

时间复杂度 O(MN) 其中M是矩阵的行数，N是矩阵的列数。 空间复杂度 O(1)
