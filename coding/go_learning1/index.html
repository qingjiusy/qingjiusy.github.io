第一个golang程序
#

hello.go代码：

package main //程序的包名

import "fmt"

//main函数
func main() {
	fmt.Println("hello Go!")
}

执行command
#

直接编译运行上面的go文件：go run hello.go。

同时也可以分步的去编译，去运行。先编译：go build hello.go，他会生成一个文件hello.exe，然后我们可以通过./hello来执行。

需要注意的地方
#

  1. 不在乎有没有分号，一般默认不加分号。
  2. 如果是导入多个包的情况下，推荐这样写：
import (
    "fmt"
    "time"
)
  1. 定义函数的时候左花括号{一定和函数名同一行！

常见的四种变量声明方法
#

  1. 方法一：声明一个变量 默认的值是0
var a int
  1. 方法二：声明一个变量，初始化一个值
var b int = 100
  1. 方法三：在初始化的时候可以省去数据类型的声明，通过值自动匹配数据类型
var c = 10000
  1. 方法四：最常用的方法，省去var关键字，直接自动匹配
e := 999

但是要注意方法四是不能定义全局变量的！

多个变量的定义
#

主要有两种方法：

// 声明多个变量
	var xx, yy = 11, "helloyy"
	fmt.Println(xx, yy)

	// 多行的多变量声明
	var (
		zz = 66
		kk = "ctrl"
	)
	fmt.Println(zz, kk)

常量 const与iota知识点
#

常量是不允许修改的，用const来定义。

可以在const()添加一个关键字iota， 每行的iota都会累加1, 第一行的iota的默认值是0。

而且要注意，一旦iota相关的公式在const中定义之后，后面的常量赋值会继承这个公式：

const (
	//可以在const() 添加一个关键字 iota， 每行的iota都会累加1, 第一行的iota的默认值是0
	BEIJING = 10*iota	 //iota = 0，输出是0
	SHANGHAI 		  //iota = 1，输出是10
	SHENZHEN          //iota = 2，输出是20
)

在一行赋值多个常量的情况下，要注意iota是逐行递增的：

const (
	a, b = iota+1, iota+2 // iota = 0, a = iota + 1, b = iota + 2, a = 1, b = 2
	c, d				  // iota = 1, c = iota + 1, d = iota + 2, c = 2, d = 3
	e, f				  // iota = 2, e = iota + 1, f = iota + 2, e = 3, f = 4

	g, h = iota * 2, iota *3  // iota = 3, g = iota * 2, h = iota * 3, g = 6, h = 9 
	i, k					   // iota = 4, i = iota * 2, k = iota * 3 , i = 8, k = 12
)

要注意，iota只能出现在const()中！只有在const里面进行累加效果！

函数
#

最基础的函数格式，返回一个值：

func foo1(a string, b int) int {
	fmt.Println("a = ", a)
	fmt.Println("b = ", b)

	c := 100

	return c
}

函数返回两个值：

//返回多个返回值，匿名的
func foo2(a string, b int) (int, int) {
	fmt.Println("a = ", a)
	fmt.Println("b = ", b)

	return 666, 777
}

//返回多个返回值， 有形参名称的
func foo3(a string, b int) (r1 int, r2 int) {
	fmt.Println("---- foo3 ----")
	fmt.Println("a = ", a)
	fmt.Println("b = ", b)



	//r1 r2 属于foo3的形参，  初始化默认的值是0
	//r1 r2 作用域空间 是foo3 整个函数体的{}空间
	fmt.Println("r1 = ", r1)
	fmt.Println("r2 = ", r2)


	//给有名称的返回值变量赋值
	r1 = 1000
	r2 = 2000

	return
}

注意在这里有名称的返回值，是通过对这个名称的变量进行赋值来的。如果没有赋值的话，就是默认值。

import导包路径与init方法调用
#

导包的时候基本流程就是这样。在Go语言中，每当你导入一个包时，如果该包中定义了init()函数，这个函数会在使用该包之前自动执行，无需手动调用。

注意点
#

函数名（以及变量名、常量名、类型名等）首字母是否大写，决定了它的“可见性（visibility）”。

  • 如果一个函数、变量、类型等的名字首字母是大写的，那么这个标识符是导出的（Exported）。
  • 导出的内容可以在其他包中被访问使用。

如果是小写：

  • 包外不可见（未导出）
  • 小写开头的函数、变量等，只能在定义它的包内部访问，其他包不能访问。

import匿名以及别名导包方式
#

在go中，你导入包但是不使用包是会报错的，但是如果我们现在有一个情况：只想使用包中的init函数，而不使用其他函数。

这种情况下，我们可以使用匿名方式导包，也就是加上_（匿名方式导包的话，使用不了包中的函数，这个方式设计就是为了只使用init函数）。

同时也可以使用别名来命名包，在包路径在加上就可以。

也可以在包路径前用.，意味着把导入的包全部放到当前包中，这样的话就可以直接用导入的包中的函数了（但是点其实最好不要轻易使用，因为函数有可能重名）：

package main

import (
	_ "GolangStudy/5-init/lib1"
	mylib2 "GolangStudy/5-init/lib2"
	//. "GolangStudy/5-init/lib2"
)

func main() {
	//lib1.lib1Test()

	//lib2.Lib2Test()
	mylib2.Lib2Test()
	//Lib2Test()
}

指针
#

Go语言中的指针其实和C语言类似，但比C安全、简洁一些，也更符合Go的语法风格。

  1. 取地址符号：&
  2. 解引用符号：*
package main

import "fmt"

func changeValue(p *int) {
    *p = 10
}

func main() {
    var a int = 1
    changeValue(&a)
    fmt.Println("a = ", a)
}

在这段简易代码中，我们把&a，也就是a的地址传入给p，然后通过*p操作指向的数据。

和C语言一样，有二级三级这样的多级指针。

defer语句调用顺序
#

defer是一个非常有用的关键字，用于延迟执行某个函数，直到包含它的函数执行完毕（即将返回）的时候才会执行。

比如下面这个代码：

package main

import "fmt"

func main() {
	//写入defer关键字
	defer fmt.Println("main end1")
	defer fmt.Println("main end2")


	fmt.Println("main::hello go 1")
	fmt.Println("main::hello go 2")
}

输出结果（可以看到先写的defer后执行，因为这在底层逻辑上是一个压栈出栈的操作！）：

main::hello go 1
main::hello go 2
main end2
main end1

还有一点要注意的是，在函数中，**return先于defer执行！**理解上的话就是，defer中的语句是在当前函数的生命周期结束时才会去执行的！

数组与动态数组
#

定义一个固定长度为10的数组：var myArray1 [10]int。

定义一个固定长度为10的数组，数组前四个元素是1 2 3 4：myArray2 := [10]int{1,2,3,4}。

注意，在函数中通过形参传递数组是值传递，是弱拷贝，形参只是原来数组的一个副本，原来的数组不受影响。

动态数组slice的定义：myArray := []int{1,2,3,4}。不写长度。

不同于函数中形参是数组的情况，如果形参是slice，那么不再是值传递，而是引用传递！

slice切片的四种声明定义方式
#

  1. 声明slice1是一个切片，并且初始化，默认值是1，2，3。 长度len是3：slice1 := []int{1, 2, 3}
  2. 声明slice1是一个切片，但是并没有给slice分配空间： var slice1 []int，后续可以给它开辟空间，默认值是0：slice1 = make([]int, 3)。
  3. 声明slice1是一个切片，同时给slice分配空间，3个空间，初始化值是0：var slice1 []int = make([]int, 3)。
  4. 声明slice1是一个切片，同时给slice分配空间，3个空间，初始化值是0, 通过:=推导出slice是一个切片：slice1 := make([]int, 3)。

slice切片追加
#

来看看这串代码：var numbers = make([]int, 3, 5)

make是Go提供的内建函数，用于创建slice（切片）、map或channel。

在这里，创建了一个元素类型为int的切片：

  • 长度（len）为 3：切片当前包含3个元素
  • 容量（cap）为 5：底层数组可以容纳最多5个元素

向numbers切片追加一个元素1：numbers = append(numbers, 1)。

问题：如果append增加的元素超过了切片的cap上限(也就是长度超过容量)，会怎么样？

不会报错！slice会自动“扩容”生成一个新的切片副本，新的会增加原来的一个cap容量。

**注意事项：**append返回的是新的切片，所以你需要接收它的返回值，否则新切片会丢失：s = append(s, newElement) // 必须赋值回来！

切片截取
#

和python差不多。左闭右开。

s := []int{1, 2, 3} //len = 3, cap = 3, [1,2,3]

//[0, 2)
s1 := s[0:2] // [1, 2]

注意这里的s1实质上指向的就是s的地址，也就是浅拷贝！

浅拷贝是指：拷贝的是对象的“引用”，而不是对象本身的数据副本。 也就是说：两个变量拥有不同的引用变量，但共享相同的底层数据。

如果不想使用浅拷贝，我们可以使用copy方法来将底层数组的slice一起进行拷贝。

//将s中的值 依次拷贝到s2中
copy(s2, s)

map
#

在 Go 语言中，map是一种内建的数据结构，用来存储键值对（key-value）。类似Python中的字典（dict）或JavaScript中的对象那样的结构。

map的三种声明定义方式
#

声明myMap1是一种map类型，其中key是string，value是string：var myMap1 map[string]string。

在使用map前，需要先用make给map分配数据空间：

  1. myMap1 = make(map[string]string, 10)。
  2. myMap2 := make(map[int]string) 注意这里没有指定长度或容量，不同于切片那样了。这样写的是创建一个空的map，容量默认由Go自动管理。后续直接加元素就行。
  3. 直接写里面的元素：
myMap3 := map[string]string{
	"one":   "php",
	"two":   "c++",
	"three": "python",
}

map的使用方式
#

添加
#

直接写：

cityMap := make(map[string]string)

//添加
cityMap["China"] = "Beijing"
cityMap["Japan"] = "Tokyo"
cityMap["USA"] = "NewYork"

遍历
#

获得它的key和value。

for key, value := range cityMap {
	fmt.Println("key = ", key)
	fmt.Println("value = ", value)
}

删除
#

指定key表示删除哪一行：

//删除
delete(cityMap, "China")

修改
#

直接改

//修改
cityMap["USA"] = "DC"
ChangeValue(cityMap)

注意点
#

map作为函数形参时，传递是引用传递！可以在函数内部修改map。

如果我们想对一个map进行完全拷贝，我们只需要再定义一个map，然后依次遍历，重新赋值就可以了。
