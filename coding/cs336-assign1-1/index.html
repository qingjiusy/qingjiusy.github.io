CS336 Assignment 1 · 交互式学习笔记本

线性层（Linear）和嵌入（Embedding）是 Transformer 里最基础的两块积木，几乎所有其他模块都建立在它们之上。这一章帮你建立它们的几何/机制直觉，最后给出"带步骤注释的骨架"让你自己填实现。

学习目标
#

  1. 理解线性层"做了什么"——从矩阵乘到几何变换（旋转+缩放+投影）。
  2. 记牢权重形状约定 (d_out, d_in)，并想清楚前向里"谁和谁收缩"。
  3. 亲手验证线性层的线性性质（可加性 + 齐次性）。
  4. 理解嵌入的本质是查表（按 id 取行），不是矩阵乘。
  5. 拿到两个模块的引导骨架，知道自己该在 cs336_basics/ 里写什么。

学术诚信：下面用 nn.Linear / nn.Embedding 当"参考教具"来展示行为与性质，不展示"某表达式恰好等于参考输出"这种解答。真正的实现表达式留白（...）给你写。

import torch
import torch.nn as nn
import numpy as np
import matplotlib.pyplot as plt

torch.set_printoptions(precision=4, sci_mode=False)
torch.manual_seed(0)
print("setup ok | torch", torch.__version__)

Part A · 线性层
#

A.1 它做了什么
#

一个（无 bias 的）线性层把输入的最后一维从 d_in 变换到 d_out。前导维度 ...（batch、seq）原样保留。作业里的权重形状约定是 (d_out, d_in)。

下面用 nn.Linear(bias=False) 当黑箱参考，只看它的输入输出行为：它把 (4, 12, 64) 变成 (4, 12, 128)，nn.Linear只作用在最后一维，前面的维度只是“批量维度”，它们彼此之间不会互相影响。

# nn.Linear这个层对象本身没有shape属性。因此要使用weight.shape。
ref = nn.Linear(in_features=64, out_features=128, bias=False)
print("权重形状 weight.shape :", tuple(ref.weight.shape), "  <- (d_out, d_in)")

x = torch.randn(4, 12, 64)
y = ref(x)
print("输入 :", tuple(x.shape))
print("输出 :", tuple(y.shape), "  <- 只有最后一维变了，前导维 (4,12) 保留")

# 前导维度是逐元素独立的：单独喂一个 token，应等于整批里对应那个 token 的结果
single = ref(x[0, 0])
print("\n单个 token 输出 shape :", tuple(single.shape))
print("和整批里 [0,0] 位置一致 :", torch.allclose(single, y[0, 0], atol=1e-6))

权重形状 weight.shape : (128, 64)   <- (d_out, d_in)
输入 : (4, 12, 64)
输出 : (4, 12, 128)   <- 只有最后一维变了，前导维 (4,12) 保留

单个 token 输出 shape : (128,)
和整批里 [0,0] 位置一致 : True

A.2 “线性"到底意味着什么
#

线性 = 满足可加性 $f(a+b)=f(a)+f(b)$ 和齐次性 $f(\alpha x)=\alpha f(x)$。这不是废话——正因为线性，多个连续的线性层可以合并，这也是为什么 Transformer 里必须在中间插入非线性激活（下一章的 SiLU），否则整个网络会塌缩成一个线性变换。下面亲手验证这两条性质。

f = nn.Linear(5, 3, bias=False)
a = torch.randn(5)
b = torch.randn(5)
alpha = 2.5

add_lhs, add_rhs = f(a + b), f(a) + f(b)
hom_lhs, hom_rhs = f(alpha * a), alpha * f(a)

print("可加性  f(a+b) == f(a)+f(b) :", torch.allclose(add_lhs, add_rhs, atol=1e-6))
print("齐次性  f(2.5a) == 2.5 f(a) :", torch.allclose(hom_lhs, hom_rhs, atol=1e-6))
print("\n=> 两个线性层叠加仍是线性；所以模型里要靠激活函数引入非线性。")

可加性  f(a+b) == f(a)+f(b) : True
齐次性  f(2.5a) == 2.5 f(a) : True

=> 两个线性层叠加仍是线性；所以模型里要靠激活函数引入非线性。

A.3 几何直觉：线性变换是对空间的"拉伸+旋转”
#

把线性层看成对整个空间的变换最直观。下面取一个 2→2 的线性层，看它如何把单位圆和标准基向量映射过去——圆会变成椭圆（各方向的拉伸不同），基向量会被旋转/缩放。高维时同理，只是我们画不出来。

torch.manual_seed(3)
g = nn.Linear(2, 2, bias=False)
W = g.weight.detach() #detach()的意思是：从计算图里分离出来，得到一个不再参与梯度追踪的张量。

# 单位圆上的点
# torch.linspace(start, end, steps)：生成从 start 到 end 的等间隔数值。
# torch.cos，torch.sin：取余弦，正弦
# torch.stack：把多个形状相同的张量沿一个新维度拼起来。
t = torch.linspace(0, 2 * np.pi, 200) # （200，）
circle = torch.stack([torch.cos(t), torch.sin(t)], dim=1)   # (200, 2)
mapped = g(circle).detach() # 把circle输入到线性层g里面

# torch.eye(n)：会创建一个 n x n 的二维张量，对角线是 1，其他位置是 0。
# 标准基向量 e1, e2 及其像
basis = torch.eye(2)
basis_mapped = g(basis).detach()

fig, ax = plt.subplots(1, 2, figsize=(9, 4.2))
ax[0].plot(circle[:, 0], circle[:, 1]); ax[0].set_title("input: unit circle + basis")
ax[0].quiver([0, 0], [0, 0], basis[:, 0], basis[:, 1], color=["r", "g"], scale=1, scale_units="xy", angles="xy")
ax[1].plot(mapped[:, 0], mapped[:, 1]); ax[1].set_title("output: ellipse (stretched+rotated)")
ax[1].quiver([0, 0], [0, 0], basis_mapped[:, 0], basis_mapped[:, 1], color=["r", "g"], scale=1, scale_units="xy", angles="xy")
for a_ in ax: a_.set_aspect("equal"); a_.grid(alpha=0.3); a_.axhline(0, lw=0.5, c="k"); a_.axvline(0, lw=0.5, c="k")
plt.tight_layout(); plt.show()
print("权重 W =\n", W)
print("红/绿箭头 = 基向量 e1,e2 变换后的落点，正好是 W 的两列。")


权重 W =
 tensor([[-0.7011, -0.5578],
        [-0.3029, -0.6690]])
红/绿箭头 = 基向量 e1,e2 变换后的落点，正好是 W 的两列。

A.4 ✏️ 你的任务：Linear 引导骨架
#

下面是给你填的骨架（不可直接运行，... 处留白）。关键是想清楚 A.1 里的形状约定：权重是 (d_out, d_in)，输入最后一维是 d_in，输出最后一维要变成 d_out——哪一维和哪一维收缩？需要转置吗？ 拿个 (2,3) 的小例子在纸上摆一下就清楚了。

提示：初始化用截断正态（handout 有给 std），但测试会直接塞权重进来，所以初始化不影响单测、影响的是后面训练。

class Linear(nn.Module):
    def __init__(self, d_in: int, d_out: int):
        super().__init__()
        # step 1: 建一个形状为 (d_out, d_in) 的可学习参数
        # nn.Parameter(...)：告诉 PyTorch：“这是模型参数，需要被训练”
        # torch.randn 和 torch.empty 最大区别是：前者会写入随机值，后者只分配内存但不填值。
        self.weight = nn.Parameter(torch.empty(d_out, d_in))
        # step 2: 按 handout 的截断正态初始化它（可选，不影响单测）
        # 最后有_，表示此api是原地修改
        nn.init.trunc_normal_(self.weight)

    def forward(self, x):
        # step 3: 把 x 的最后一维 (d_in) 与 weight 的 d_in 维收缩，得到最后一维 d_out
        #   想清楚是 x @ weight 还是 x @ weight.T —— 用小例子核对形状
        #   （einsum 也可以：给每个维度起名，让收缩的维同名）
        # return ...
        return x @ self.weight.T

print("  pytest tests/test_model.py::test_linear -x")

Part B · 嵌入
#

B.1 嵌入是查表，不是矩阵乘
#

嵌入层持有一张 (vocab_size, d_model) 的表，每个 token id 对应表里的一行。前向就是按 id 把对应的行取出来——本质是索引（gather），不是矩阵乘法。用 one-hot 乘权重在数学上等价，但慢且没必要。

下面用 nn.Embedding 当参考，观察它的行为与性质：输出形状 = ids.shape + (d_model,)；同一个 id 永远映射到同一个向量。（ids通常指 token id / 索引编号，也就是一堆整数。）

emb = nn.Embedding(num_embeddings=10, embedding_dim=4)
print("表的形状 :", tuple(emb.weight.shape), "  <- (vocab_size, d_model)")

ids = torch.tensor([[1, 1, 2], [3, 0, 1]])   # (2, 3)，表示2个batch，sequence长度是3
out = emb(ids) # 可以近似理解为emb.weight[ids]，只是因为这里emb是nn.Embedding类
print("ids  :", tuple(ids.shape))
print("out  :", tuple(out.shape), "  <- = ids.shape + (d_model,)")

# 性质：同一个 id -> 同一个向量（这里所有 id==1 的位置）
v_a = out[0, 0]   # ids[0,0]==1
v_b = out[0, 1]   # ids[0,1]==1
v_c = out[1, 2]   # ids[1,2]==1
print("\nid=1 在三个不同位置取到的向量是否完全相同:",
      torch.equal(v_a, v_b) and torch.equal(v_b, v_c))

表的形状 : (10, 4)   <- (vocab_size, d_model)
ids  : (2, 3)
out  : (2, 3, 4)   <- = ids.shape + (d_model,)

id=1 在三个不同位置取到的向量是否完全相同: True

🔬 实验：嵌入是可学习的"语义坐标"。随机初始化的嵌入没有意义，但训练后相似的 token 会靠得更近。这里手动构造一个 2 维的小表来体会"每个 token 就是空间里的一个点"——训练的目标就是把这些点挪到有意义的位置。

words = ["cat", "dog", "kitten", "puppy", "car", "truck"]
# 手工摆一个“理想”布局：宠物在左簇，车辆在右簇（仅示意，不是训练结果）
coords = torch.tensor([[-2.0, 1.0], [-1.6, 1.4], [-2.2, 0.4],
                       [-1.4, 0.6], [2.0, -0.5], [1.6, -1.1]])
table = nn.Embedding.from_pretrained(coords) # 用你给定的张量 coords 直接创建一个 Embedding 表

pts = table(torch.arange(len(words))).detach() # 把 words 里的所有词对应的 embedding 坐标一次性取出来，然后断开梯度追踪
plt.figure(figsize=(5, 4))
plt.scatter(pts[:, 0], pts[:, 1])
for i, w in enumerate(words):
    plt.annotate(w, (pts[i, 0] + 0.05, pts[i, 1] + 0.05))
plt.title("embedding: each token is a point in space")
plt.grid(alpha=0.3); plt.axhline(0, lw=0.5, c="k"); plt.axvline(0, lw=0.5, c="k")
plt.tight_layout(); plt.show()
print("训练做的事：通过梯度把这些点挪到让语言建模 loss 更低的位置。")


训练做的事：通过梯度把这些点挪到让语言建模 loss 更低的位置。

B.2 ✏️ 你的任务：Embedding 引导骨架
#

核心就一个动作：用 token_ids 作为行索引，从 (vocab_size, d_model) 的表里一次性取出对应行。PyTorch 的高级索引（integer indexing）能直接做到，不用循环、不用 one-hot。想清楚输出 shape 应该是 token_ids.shape + (d_model,)。

PyTorch 的高级索引之一是：假设有一个张量 x 和一个整型张量 y，那么可以写 x[y]。 当 y 被放在第一个索引位置时，y 里的每个整数会被当作 x 第 0 维的下标，用来取 x 的对应元素/行。 如果 x 是二维矩阵，那么就是取对应行；如果 x 是更高维张量，就是取第 0 维上对应的切片。

class Embedding(nn.Module):
    def __init__(self, vocab_size: int, d_model: int):
        super().__init__()
        # step 1: 建一个形状 (vocab_size, d_model) 的可学习查找表
        self.weight = nn.Parameter(torch.zeros(vocab_size, d_model))
        # step 2: 按 handout 初始化（可选）
        return

    def forward(self, token_ids):
        # step 3: 用 token_ids 作为“行下标”索引 self.weight
        #   —— 高级索引：weight[<某个整型张量>] 会一次取出所有对应行
        #   自问：返回的 shape 是不是 token_ids.shape + (d_model,)？
        # r整数张量索引
        return self.weight[token_ids]

print("填好后接线到 run_embedding，跑：pytest tests/test_model.py::test_embedding -x")

🔬 拓展实验（自己动手，加深理解）
#

  1. 转置方向验证：在 A.4 骨架里故意用错 x @ weight（不转置），跑 test_linear，看报的是形状错误还是数值错误。理解错误信息能帮你快速定位。
  2. 前导维度通用性：给你的 Linear 喂 (64,)、(12, 64)、(4, 12, 64) 三种输入，确认都能正确输出。这对应 adapters 里的 ... d_in 约定。
  3. 嵌入的梯度：对 nn.Embedding 的输出求和再 .backward()，打印 emb.weight.grad，观察"只有被用到的行才有梯度"。想想这对稀疏更新意味着什么。
  4. one-hot 等价性（仅理解，别在作业里这么写）：手推一下"one-hot 向量 × 权重矩阵"为什么等于取某一行，从而理解为什么直接索引更高效。

回答
#

  1. 这里的“稀疏更新”的含义是：每个 batch 只更新这个 batch 里出现过的 token 的 embedding。如果这个embedding在这个batch都不存在的话，就没有被用，就没有梯度，因此就不会被训练更新embedding这个张量。
  2. 就是相等，得到的也是一行。但是这样的话其实是要进行一次矩阵计算的，不如直接索引高效。

小结
#

  • 线性层 = 对最后一维的线性变换（几何上是拉伸+旋转+投影），权重形状 (d_out, d_in)，无 bias。
  • 线性性质决定了必须有非线性激活，否则网络塌缩。
  • 前向的关键是想清楚哪一维收缩、要不要转置——用小例子核对，别靠猜。
  • 嵌入 = (vocab_size, d_model) 查找表，前向是按 id 取行（高级索引），输出 ids.shape + (d_model,)。
