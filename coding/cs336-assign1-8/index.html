CS336 Assignment 1 · 交互式学习笔记本

到这一章，你已经写好了一堆"积木"：Linear、Embedding、RMSNorm、SwiGLU、RoPE、以及缩放点积注意力（SDPA）。这一章不再造新算法，而是把这些积木装配成三样东西：

  1. 多头自注意力（Multi-Head Self-Attention, MHA）
  2. Transformer block（pre-norm 残差结构）
  3. 完整的 Transformer 语言模型（LM）

所以本章的关键词是装配直觉：形状怎么在头之间拆开又拼回、因果掩码在讲什么、pre-norm 的残差结构长什么样、整条前向怎么串起来。

学习目标
#

  1. 理解"多头"= 把 d_model 拆成 num_heads × d_head，每个头在各自的子空间独立做注意力，再拼回来。
  2. 看清一次矩阵乘就能算出所有头的 Q/K/V 投影，以及权重 (d_model, d_model) 的行是怎么按 (num_heads, d_head) 排列的。
  3. 通过可视化体会不同的头关注不同的位置，以及因果掩码的含义。
  4. 建立 pre-norm vs post-norm 的稳定性直觉。
  5. 拿到 MHA / block / LM 三个引导骨架，知道该怎么用前面的积木把它们拼出来。

Part A · 多头的机制：把 d_model 拆成头，再拼回来
#

A.1 为什么要多头
#

单个注意力头只能学一种“谁该看谁"的关系。多头的想法是：把 d_model 维切成 num_heads 份，每份 d_head = d_model // num_heads 维，让每个头在自己的低维子空间里独立做注意力——有的头可能学"看前一个词”，有的头学"看句首"，有的学"看语法上相关的词"。最后把所有头的结果拼接起来，再过一个输出投影混合信息。

工程上有个关键点：num_heads 个头的 Q/K/V 投影不必分别做，而是用一次 (d_model, d_model) 的矩阵乘算出全部，再把最后一维 reshape 成 (num_heads, d_head)。作业 docstring 里说 q_proj.weight 的行是按 (num_heads, d_head) 顺序拼起来的，就是这个意思。

所以装配 MHA 的核心动作只有两个形状变换：拆头和拼头。下面（承接第 00 章）只看 shape。

# 只演示形状：投影完之后是 (batch, seq, d_model)，要把最后一维拆成 (num_heads, d_head)
batch, seq = 4, 12
projected = torch.randn(batch, seq, D_MODEL)          # 假装这是 q/k/v 投影后的结果
print("投影后           :", tuple(projected.shape), "  (batch, seq, d_model)")

# 拆头：把 (h d) 拆开，并把 head 维挪到 seq 前面 —— 每个头拿到 (seq, d_head)
per_head = rearrange(projected, "b s (h d) -> b h s d", h=N_HEADS)
print("拆成多头         :", tuple(per_head.shape), "  (batch, num_heads, seq, d_head)")

# 拼头：注意力算完后，逆变换把头拼回 d_model
merged = rearrange(per_head, "b h s d -> b s (h d)")
print("拼回             :", tuple(merged.shape), "  (batch, seq, d_model)")

# 拆-拼是可逆的：round-trip 应完全还原
print("\n拆头再拼头 == 原张量 :", torch.equal(merged, projected))
print("=> MHA 里你只需要这两个 rearrange，注意力本身复用你写好的 SDPA。")

Part B · 不同的头关注不同的位置（含因果掩码）
#

概念说完，来"看"一眼注意力到底在做什么。下面用 nn.MultiheadAttention 当参考教具（作业里禁止用它），对一个玩具序列跑一遍，把每个头的注意力权重画成热图。

两个观察点：

  • 因果掩码：语言模型只能"看过去"。给注意力加一个因果 mask 后，位置 i 只能注意到位置 j ≤ i，所以热图会呈现下三角结构（右上角为 0）。你在 block 内部要自己构造这个 mask。
  • 头的多样性：同一层的不同头，注意力分布明显不同——这正是"多头"的价值。

注意：nn.MultiheadAttention 的 attn_mask 约定是 True = 屏蔽，而你自己 SDPA 的 mask 约定可能相反（True = 保留）。所以这段代码不能照抄进作业，它只是让你"看见"模式。

torch.manual_seed(1)
L = 8
ref_mha = nn.MultiheadAttention(embed_dim=D_MODEL, num_heads=N_HEADS,
                                batch_first=True, bias=False)
x = torch.randn(1, L, D_MODEL)

# 因果 mask（参考教具的约定：True = 不允许注意）：位置 i 不能看 j>i
causal = torch.triu(torch.ones(L, L, dtype=torch.bool), diagonal=1)

with torch.no_grad():
    _, attn_w = ref_mha(x, x, x, attn_mask=causal,
                        need_weights=True, average_attn_weights=False)
# attn_w: (batch=1, num_heads, query=L, key=L)
attn_w = attn_w[0]
print("每个头的注意力权重 shape :", tuple(attn_w.shape), "  (num_heads, query, key)")

fig, axes = plt.subplots(1, N_HEADS, figsize=(3.0 * N_HEADS, 3.2))
for h in range(N_HEADS):
    ax = axes[h]
    im = ax.imshow(attn_w[h], cmap="viridis", vmin=0, vmax=1)
    ax.set_title(f"head {h}")
    ax.set_xlabel("key (attended to)")
    if h == 0: ax.set_ylabel("query (position)")
    ax.set_xticks(range(L)); ax.set_yticks(range(L))
fig.colorbar(im, ax=axes, fraction=0.02, pad=0.02, label="attention weight")
fig.suptitle("Per-head causal attention (lower-triangular = can't see the future)")
plt.show()

print("每行加起来应为 1（softmax 归一化）:", torch.allclose(attn_w.sum(-1), torch.ones(N_HEADS, L), atol=1e-5))
print("右上角（未来位置）应为 0，且各头分布明显不同。")

Part C · Transformer block：pre-norm 残差结构
#

一个 Transformer block 由两个子层组成，每个子层都套在一个残差连接里：

  1. 注意力子层：x = x + MHA(RMSNorm(x))
  2. 前馈子层： x = x + SwiGLU(RMSNorm(x))

注意归一化放在子层的输入侧（先 norm 再进子层，残差直接加原始 x）——这叫 pre-norm。另一种老式做法是 post-norm：x = RMSNorm(x + Sublayer(x))，把 norm 套在整个残差和外面。

为什么现在都用 pre-norm？直觉是：pre-norm 给了一条从输入直达输出的**“残差高速路”**（identity path），信号和梯度可以几乎无损地穿过很多层；而 post-norm 每层都把整个残差流重新缩放一遍，深层堆叠时更难训练、更依赖 warmup。下面用一个玩具模拟把这条"高速路"画出来。

torch.manual_seed(0)
depth = 40
d = D_MODEL
x0 = torch.randn(1, 8, d)

# 固定的随机"子层"，当作 Attn/FFN 的替身（两种结构用同一个，保证公平对比）
sublayer = nn.Linear(d, d, bias=False)

# 归一化替身：这里用 LayerNorm，重点是"norm 放在哪儿"，不是用哪种 norm
def norm(t):
    return F.layer_norm(t, (d,))

pre_curve, post_curve = [], []
xp = x0.clone()   # pre-norm 残差流
xq = x0.clone()   # post-norm 残差流
with torch.no_grad():
    for _ in range(depth):
        xp = xp + sublayer(norm(xp))     # pre-norm: norm 在子层输入侧，残差是干净的 identity
        xq = norm(xq + sublayer(xq))     # post-norm: norm 套在整个残差和外面
        pre_curve.append(xp.norm(dim=-1).mean().item())
        post_curve.append(xq.norm(dim=-1).mean().item())

plt.figure(figsize=(6, 4))
plt.plot(range(1, depth + 1), pre_curve, label="pre-norm (residual highway)")
plt.plot(range(1, depth + 1), post_curve, label="post-norm (re-normalized each layer)")
plt.xlabel("depth (layer index)"); plt.ylabel("mean activation L2 norm")
plt.title("Residual stream norm vs depth"); plt.legend(); plt.grid(alpha=0.3)
plt.tight_layout(); plt.show()

print("pre-norm 的范数随深度平滑增长 => 存在一条直达的 identity 通路（残差高速路）。")
print("post-norm 每层都把整条流重新缩放 => 深层堆叠时更难优化。")

✏️ 你的任务 1：多头自注意力（引导骨架）
#

下面是给你填的骨架，只画出"装配流水线"，每一步都留白（...）。核心是复用你已经写好的积木（Linear / RoPE / Scaled Dot-Product Attention(SDPA)），而不是重写注意力。

装配流水线（对照 docstring 的权重形状 (d_model, d_model)、行按 (num_heads, d_head) 排列）：

  • 一次矩阵乘做 Q/K/V 投影 → 用 Part A 的 rearrange 拆头 → （RoPE 版）对 q,k 施加 RoPE → 构造因果 mask → 调用你的 SDPA → 拼头 → 过输出投影。

自问几个问题：拆头的目标形状是什么（回看 A.1）？你的 SDPA 的 mask 约定是 True=保留还是 True=屏蔽？RoPE 作用在哪一维（d_head 还是 d_model）？

from cs336_basics.linear import Linear
from cs336_basics.rope import RotaryPositionalEmbedding
from cs336_basics.attention import scaled_dot_product_attention
from einops import rearrange
import torch
import torch.nn as nn

class MultiHeadSelfAttention(nn.Module):
    def __init__(self, d_model: int, num_heads: int,
                 use_rope: bool = False, max_seq_len: int | None = None,
                 theta: float | None = None):
        super().__init__()
        self.num_heads = num_heads
        assert d_model % num_heads == 0
        self.d_head = d_model // num_heads
        self.use_rope = use_rope

        # 先想清楚: d_head = d_model // num_heads
        # step 1: 建 4 个投影 q_proj / k_proj / v_proj / output_proj —— 每个都是 (d_model, d_model)的线性层（复用你写的 Linear）。self.q_proj = ...  ...  self.o_proj = ...
        self.q_proj = Linear(d_model, d_model)
        self.k_proj = Linear(d_model, d_model)
        self.v_proj = Linear(d_model, d_model)
        self.output_proj = Linear(d_model, d_model)

        # step 2:（use_rope 时）准备一个 RoPE 模块，作用在每个头的 d_head 维上
        if(self.use_rope):
            self.RoPE = RotaryPositionalEmbedding(theta, self.d_head, max_seq_len)

    def forward(self, x, token_positions=None):
        # x: (..., seq, d_model)
        # step 1: 一次矩阵乘做投影，得到 q, k, v，每个 (..., seq, d_model)
        q = self.q_proj(x)
        k = self.k_proj(x)
        v = self.v_proj(x)

        # step 2: 拆头 —— 把最后一维拆成 (num_heads, d_head)，把 head 维挪到 seq 前
        # 目标形状 (..., num_heads, seq, d_head)
        q = rearrange(q, "... seq (num_heads d_head) -> ... num_heads seq d_head", num_heads = self.num_heads, d_head = self.d_head)   
        k = rearrange(k, "... seq (num_heads d_head) -> ... num_heads seq d_head", num_heads = self.num_heads, d_head = self.d_head)    
        v = rearrange(v, "... seq (num_heads d_head) -> ... num_heads seq d_head", num_heads = self.num_heads, d_head = self.d_head) 

        # step 3:（use_rope 时）对 q, k 施加 RoPE（复用你写的 RoPE；注意作用在 d_head 维）
        # token_positions:(..., seq)
        if(self.use_rope):
            if(token_positions == None):
                token_positions = torch.ones(q.shape[:-1], dtype=torch.long) * torch.arange(q.shape[-2], dtype=torch.long)
            q = self.RoPE(q, token_positions)
            k = self.RoPE(k, token_positions)

        # step 4: 构造因果 mask —— query i 只能看到 key j <= i，之前构造的attention中True=保留 / False=屏蔽
        # 构造一个(seq, seq)的mask，然后之后用的时候直接广播到(..., num_heads, seq, seq)
        mask = torch.tril(torch.ones(x.shape[-2], x.shape[-2], dtype=torch.bool)) # (seq, seq)

        # step 5: 调用你写的 SDPA，得到每个头的输出 
        attn = scaled_dot_product_attention(q, k, v, mask) # (..., num_heads, seq, d_head)

        # step 6: 拼头 —— 把 (num_heads, d_head) 拼回 d_model
        attn = rearrange(attn, "... num_heads seq d_head -> ... seq (num_heads d_head)") # (..., seq, d_model)

        # step 7: 过输出投影 output_proj 并返回
        # 过输出投影 output_proj 是为了让不同 head 的信息发生融合。下一层就可以收到已经混合好的表示。
        return self.output_proj(attn)

print("MHA 骨架已定义（未实例化）。填好后接线到 run_multihead_self_attention[_with_rope]。")

✏️ 你的任务 2：Transformer block（引导骨架）
#

有了 MHA，block 就是把 Part C 的两句公式翻译成代码——全用你已有的积木（两个 RMSNorm、一个 MHA、一个 SwiGLU）。注意 pre-norm 的位置：归一化在子层输入侧，残差直接加原始 x。权重键名参照 docstring：ln1 / attn.* / ln2 / ffn.w1|w2|w3。

from cs336_basics.rmsnorm import RMSNorm
from cs336_basics.multi_head_self_attention import MultiHeadSelfAttention
from cs336_basics.swiGLU import SwiGLU

class TransformerBlock(nn.Module):
    def __init__(self, d_model: int, num_heads: int, d_ff: int,
                 max_seq_len: int | None = None, theta: float | None = None):
        super().__init__()
        # step 1: 两个 RMSNorm（ln1, ln2）、一个 MHA(attn, 带 RoPE)、一个 SwiGLU(ffn)
        self.ln1, self.ln2 = RMSNorm(d_model=d_model), RMSNorm(d_model=d_model)

        self.attn = MultiHeadSelfAttention(
            d_model=d_model,
            num_heads=num_heads,
            use_rope=True,
            max_seq_len=max_seq_len,
            theta=theta,
        )

        self.ffn = SwiGLU(
            d_model=d_model, 
            d_ff=d_ff,
        )
        

    def forward(self, x, token_positions=None):
        # 子层一（pre-norm 注意力）: 残差 + attn(ln1(x))，norm 在子层输入侧
        x = x + self.attn(self.ln1(x), token_positions)
        # 子层二（pre-norm 前馈）:   残差 + ffn(ln2(x))
        x = x + self.ffn(self.ln2(x))

        return x

print("TransformerBlock 骨架已定义（未实例化）。接线到 run_transformer_block（atol=1e-4）。")

✏️ 你的任务 3：完整语言模型（引导骨架）
#

最后把 block 堆起来变成 LM。整条前向是：token 嵌入 → 依次过 num_layers 个 block → 最终 RMSNorm → lm_head 得到每个位置的下一个 token 的 logits。权重键名参照 docstring：token_embeddings / layers.{i}.* / ln_final / lm_head。

from cs336_basics.embedding import Embedding
from cs336_basics.transformer_block import TransformerBlock
from cs336_basics.rmsnorm import RMSNorm
from cs336_basics.linear import Linear

class TransformerLM(nn.Module):
    def __init__(self, vocab_size: int, context_length: int, d_model: int,
                 num_layers: int, num_heads: int, d_ff: int, rope_theta: float):
        super().__init__()
        # step 1: token 嵌入表 (vocab_size, d_model)（复用你的 Embedding）
        self.token_embeddings = Embedding(vocab_size, d_model)

        # step 2: num_layers 个 TransformerBlock，用 nn.ModuleList 堆起来
        self.layers = nn.ModuleList([
            TransformerBlock(
                d_model=d_model, 
                num_heads=num_heads, 
                d_ff=d_ff,
                max_seq_len=context_length, 
                theta=rope_theta,
            )
            for _ in range(num_layers)
        ])

        # step 3: 最终 RMSNorm（ln_final）
        self.ln_final = RMSNorm(d_model=d_model)

        # step 4: lm_head：线性 d_model -> vocab_size
        self.lm_head = Linear(d_model, vocab_size)

    def forward(self, token_ids):
        # token_ids:(batch, seq)
        # step 1: 查嵌入 -> (batch, seq, d_model)
        x = self.token_embeddings(token_ids) # (batch, seq, d_model)

        # step 2: 依次过每个 block（token_positions 可用 arange 生成）
        for block in self.layers: 
            x = block(x) # (batch, seq, d_model)

        # step 3: 过最终 norm
        x = self.ln_final(x) # (batch, seq, d_model)

        # step 4: 过 lm_head 得到 logits (batch, seq, vocab_size)
        return self.lm_head(x)


print("TransformerLM 骨架已定义（未实例化）。接线到 run_transformer_lm（atol=1e-4, rtol=1e-2）。")

🔬 拓展实验（自己动手，加深理解）
#

  1. 拆头/拼头的可逆性：把 A.2 的 round-trip 换成"先拼再拆"，或故意把 rearrange 写成 b s (d h)（把 h 和 d 顺序调换），比较结果——体会为什么头的切分顺序必须和权重的行排列一致。
  2. 因果掩码的验证：在 Part B 里去掉 attn_mask（改成非因果），再看热图——右上角不再为 0。想清楚：如果 LM 忘了加因果 mask，模型会"作弊"看到未来，训练 loss 会异常地低。
  3. 头数的极端情形：令 num_heads = 1（等价单头）和 num_heads = d_model（每个头 1 维），观察 A.2 的形状变化。思考头太多/太少各自的代价。
  4. pre vs post 的深度：把 Part C 的 depth 调到 5 和 200，观察两条曲线的差异如何随深度放大。
  5. 参数量估算：手推一个 block 的参数量（4 个 d_model×d_model 投影 + 3 个 FFN 矩阵 + 2 个 RMSNorm），再想 num_layers 层加嵌入/lm_head 的总量。这对后面的显存/scaling 讨论有用。

答案
#

  1. rearrange 不只是改变 shape，它还规定了我们如何解释原来连续排列的数据。MHA 中投影权重的行按照 (num_heads, d_head) 排列，因此拆头必须使用 (h d) -> h d；如果误写成 (d h)，虽然元素数量和 shape 都没有问题，但不同 head 的特征会被交叉重排，从而无法正确对应各个 attention head。
  2. 如果去掉attn_mask，就变成了非因果序列，一个词可以看到它后面的词。 为什么叫“作弊”呢？因为我们的模型训练的目标是用前面的所有词来预测下一个词，如果我们本身就能看到后面的所有词的话，这就是一种作弊。模型虽然可以答对，不是因为它学会了，是因为它看到了答案。loss 异常低是因为模型可以直接看到答案，训练一开始 loss 就会特别低，看起来效果就会特别好。然而这种低loss是虚假的，真实推理时，它看不到下一个位置的信息（等待模型生成），就等于它失去了它最依赖的信息，性能会急剧下降。因果 Mask 的作用不是提高 Attention 的效果，而是保证模型在训练时不能利用未来信息，从而真正学会“根据过去预测未来”。
  3. num_heads = 1的时候，整个模型实际上只有一个 Attention。一个 Head 只能学习一种 Attention 模式，比如学“语法关系”或者“长距离关系”，只有一个头的话就不能兼顾很多方面，模型的表达能力就比较弱。但是如果极端的让num_heads 太多的话，比如num_heads = d_model，一个头就只有一个数字，没有任何维度可以表达复杂特征。每个头几乎什么都学不了，信息量非常低。所以这里就存在一个权衡。
  4. Pre-Norm 的残差路径中存在更直接的恒等映射，梯度可以沿 residual connection 跨越很多层传播；而 Post-Norm 每层的梯度都必须经过 LayerNorm 的变换，层数越深，这些影响不断累积。因此在浅层网络中 Pre-Norm / Post-Norm 差别可能很小；网络越深，Pre-Norm 的梯度传播优势越明显，因此深层 Transformer 通常更容易用 Pre-Norm 稳定训练。
  5. 假设 d_model = d，d_ff = f，num_layers = L，vocab_size = V：

Attention 部分：q_proj，k_proj，v_proj，o_proj分别是 d*d，总和为4d^2

FFN 部分：如果使用SwiGLU，有三个矩阵w，总和是3df

两个RMSNorm：一个RMSNorm的参数是 d，两个总和就是2d

因此一个 block 总参数量：4d^2 + 3df + 2d，大模型中 2d 其实相对较小，估算的时候可以看作4d^2 + 3df

如果我们常见的让 f = 8/3d，一个block的参数就大约是4d^2 + 8d^2 = 12d^2。这就是一个经典结论：Transformer 每层参数量大约是 12 d_model^2。

L层transformer的参数总和就是12 Ld^2

再加 Embedding 和 LM Head:V*d + d*V = 2Vd

通常还会有一个最后的 RMSNorm，所以更精确一点的模型参数总和是：L(4d^2 + 3df + 2d) + 2Vd + d

如果 embedding 和 lm_head共享权重，那么两者实际上只需要一份参数，参数和就是：L(4d^2 + 3df + 2d) + Vd + d

因此我们就推导出了两个scaling方面的重要结论：

  • 层参数量 $\propto d_{\text{model}}^2$
  • 总参数量 $\propto Ld_{\text{model}}^2$

小结
#

  • 多头 = 把 d_model 拆成 num_heads × d_head，每个头在子空间独立做注意力，再拼头 + 输出投影；一次矩阵乘算出所有头的 Q/K/V。
  • 装配 MHA 的形状核心就是 Part A 的拆头/拼头两个 rearrange，注意力本身复用你写好的 SDPA。
  • 因果掩码让位置 i 只能看 j ≤ i（热图下三角）；block 内部要自己构造它。
  • pre-norm 残差结构 x = x + Sub(Norm(x)) 提供一条"残差高速路"，比 post-norm 更易训练深层网络。
  • 完整 LM = 嵌入 → N 个 block → 最终 RMSNorm → lm_head。本章的精神是用前面的积木装配，不是重写。
