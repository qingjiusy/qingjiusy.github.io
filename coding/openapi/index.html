具体文件API的使用
#

上传文件POST
#

对于文件，可以上传与 Assistants、Fine-tuning 和 Batch API 等功能一起配合使用。

示例请求如下：

from openai import OpenAI
client = OpenAI()

client.files.create(
  file=open("mydata.jsonl", "rb"),
  purpose="fine-tune"
)

可以看到请求正文有file file（必填，要上传的 File 对象，注意不是文件名！），还有purpose string（必填，即上传文件的预期用途）

目的字符串中，使用 “assistants” 表示 Assistants 和 Message 文件，使用 “vision” 表示 Assistants 图像文件输入，使用 “batch” 表示 Batch API，使用 “fine-tune” 进行微调。

响应如下：

{
  "id": "file-abc123",
  "object": "file",
  "bytes": 120000,
  "created_at": 1677610602,
  "filename": "mydata.jsonl",
  "purpose": "fine-tune",
}

列出文件GET
#

用于返回文件列表。

示例请求如下：

from openai import OpenAI
client = OpenAI()

client.files.list()

查询参数如下：

purpose string，可选参数，仅返回具有给定目的的文件

limit integer，可选参数，要返回的对象数量限制。

order string，可选参数，按created_at对象的时间戳。asc对于升序和desc以降序排列

after string，可选参数，用于分页的游标。after是定义您在列表中的位置的对象 ID。例如，如果您发出列表请求并收到 100 个对象，以 obj_foo 结尾，则您的后续调用可以包含 after=obj_foo 以便获取列表的下一页。

响应：


{
  "data": [
    {
      "id": "file-abc123",
      "object": "file",
      "bytes": 175,
      "created_at": 1613677385,
      "filename": "salesOverview.pdf",
      "purpose": "assistants",
    },
    {
      "id": "file-abc123",
      "object": "file",
      "bytes": 140,
      "created_at": 1613779121,
      "filename": "puppy.jsonl",
      "purpose": "fine-tune",
    }
  ],
  "object": "list"
}

检索文件GET
#

返回有关特定文件的信息。

示例请求如下：

from openai import OpenAI
client = OpenAI()

client.files.retrieve("file-abc123")

路径参数：

file_id string，必填，用于此请求的文件的 ID。

响应：

{
  "id": "file-abc123",
  "object": "file",
  "bytes": 120000,
  "created_at": 1677610602,
  "filename": "mydata.jsonl",
  "purpose": "fine-tune",
}

删除文件DELETE
#

删除文件。

示例请求如下：

from openai import OpenAI
client = OpenAI()

client.files.delete("file-abc123")

路径参数：

file_id string，必填，用于此请求的文件的 ID。

响应：

{
  "id": "file-abc123",
  "object": "file",
  "deleted": true
}

检索文件内容GET
#

返回指定文件的内容。

示例请求如下：

from openai import OpenAI
client = OpenAI()

content = client.files.content("file-abc123")

路径参数：

file_id string，必填，用于此请求的文件的 ID。

响应：

返回文件内容

file 对象
#

这File object 表示已上传到 OpenAI 的文档。

{
  "id": "file-abc123",
  "object": "file",
  "bytes": 120000,
  "created_at": 1677610602,
  "expires_at": 1680202602,
  "filename": "salesOverview.pdf",
  "purpose": "assistants",
}

id string:文件标识符，可在 API 终端节点中引用。

bytes integer:文件大小（以字节为单位）。

created_at integer:创建文件时的 Unix 时间戳（以秒为单位）。

expires_at integer:文件过期的 Unix 时间戳（以秒为单位）。

filename string:文件名。

object string:对象类型，始终为file。

purpose string:文件的预期用途。支持的值包括assistants, assistants_output, batch, batch_output, fine-tune, fine-tune-results和 vision.
