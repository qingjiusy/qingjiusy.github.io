CS336 Assignment 1 · 交互式学习笔记本

上一章我们验证了"线性层叠加仍是线性"——网络会塌缩成单个线性变换。要让网络真正有表达力，必须在中间插入非线性激活。这一章帮你建立激活函数的直觉：为什么需要它、常见激活长什么样、SiLU 有什么特别的性质，以及现代 Transformer FFN 里用的门控结构 SwiGLU。最后给"带步骤注释的骨架"让你自己填实现。

学习目标
#

  1. 亲眼看到"没有非线性 → 网络塌缩"，理解激活的存在意义（呼应第 01 章）。
  2. 对比 ReLU / Sigmoid / SiLU / GELU 的曲线和导数，理解"平滑"“非单调"这些词的含义。
  3. 掌握 SiLU（也叫 Swish）的定义 $\mathrm{SiLU}(x)=x\cdot\sigma(x)$ 与性质。
  4. 理解门控线性单元 GLU 的直觉：用一路当"门"调控另一路的信息流。
  5. 理解 SwiGLU 是 SiLU 门控的 FFN 变体，需要三个权重 w1, w2, w3，并想清楚它们的形状。
  6. 拿到 SiLU 与 SwiGLU 的引导骨架，知道该在 cs336_basics/ 里写什么。

学术诚信：下面用 torch.nn.functional 里的内置激活（F.silu、F.gelu、F.relu、torch.sigmoid）当"参考教具"来展示函数形状与性质——这是概念演示，不是作业解答。真正要交付的 run_silu / run_swiglu 实现表达式一律留白（...）给你写，本笔记本不包含 “我的表达式 == 参考输出” 这类验证。

Part A · 为什么需要非线性激活
#

第 01 章我们证明了线性层满足可加性与齐次性。一个直接推论：两个线性层直接相连 = 一个线性层（$W_2(W_1 x) = (W_2 W_1)x$）。不管堆多少层，只要中间没有非线性，整个网络的表达能力和单个线性层完全一样。

下面把它演示出来：把两个线性层"接起来”，看它是否等价于某一个线性层；再在中间插入一个非线性激活，看等价性如何被打破。

torch.manual_seed(0)
W1 = nn.Linear(3, 4, bias=False) # (4, 3)
W2 = nn.Linear(4, 2, bias=False) # (2, 4)
x = torch.randn(6, 3)

# 情形 1: 纯线性堆叠  y = W2(W1 x)
y_stacked = W2(W1(x))
# 它必然等于用合并权重 (W2·W1) 做的单个线性变换
W_merged = W2.weight @ W1.weight          # (2,4)@(4,3) -> (2,3)
y_single = x @ W_merged.T
print("两个线性层 == 单个合并线性层 ?", torch.allclose(y_stacked, y_single, atol=1e-6))
print("  => 没有非线性时，深度没有带来任何新的表达能力（网络塌缩）")

# 情形 2: 中间插入非线性激活 (这里用内置 SiLU 当教具)
y_nonlinear = W2(F.silu(W1(x)))
print("\n插入 SiLU 后还等于单个线性层吗 ?", torch.allclose(y_nonlinear, y_single, atol=1e-6))
print("  => 不再等价：非线性打破了塌缩，深度才有意义")

两个线性层 == 单个合并线性层 ? True
  => 没有非线性时，深度没有带来任何新的表达能力（网络塌缩）

插入 SiLU 后还等于单个线性层吗 ? False
  => 不再等价：非线性打破了塌缩，深度才有意义

Part B · 常见激活函数长什么样
#

四个常见激活：

  • ReLU $\max(0,x)$：简单高效，但在 0 处有"折角"（不平滑），且负半轴梯度恒为 0。
  • Sigmoid $\sigma(x)=\dfrac{1}{1+e^{-x}}$：把值压到 $(0,1)$，两端饱和（梯度趋于 0），常用来当"门"。
  • SiLU / Swish $x\cdot\sigma(x)$：平滑、非单调（负区间先降到一个小负值再回升），是本作业和很多现代模型的选择。
  • GELU $x\cdot\Phi(x)$：和 SiLU 形状很像，GPT 系列常用。

下面用 torch.nn.functional 的对应函数把曲线画出来（概念演示，不是实现）。

xs = torch.linspace(-6, 6, 400)
curves = {
    "ReLU":    F.relu(xs),
    "Sigmoid": torch.sigmoid(xs),
    "SiLU":    F.silu(xs),
    "GELU":    F.gelu(xs),
}
plt.figure(figsize=(6.5, 4.2))
for name, y in curves.items():
    plt.plot(xs.numpy(), y.numpy(), label=name, lw=2)
plt.axhline(0, lw=0.6, c="k"); plt.axvline(0, lw=0.6, c="k")

print("SiLU(-3) =", round(F.silu(torch.tensor(-3.0)).item(), 4), " <- 负值")

print("SiLU( 0) =", round(F.silu(torch.tensor( 0.0)).item(), 4))

B.2 导数：平滑 vs 折角
#

激活的导数决定反向传播时梯度怎么流。这里用 autograd 直接对内置激活求导并画出来，观察两件事：

  • ReLU 的导数是阶跃（0 处不连续，负半轴恒 0 —— 可能导致"死神经元"）。
  • SiLU / GELU 的导数平滑连续，而且在负区间能取到大于 1 或小于 0 的值——这正是"非单调、平滑"带来的更丰富梯度。
xs = torch.linspace(-6, 6, 400, requires_grad=True)

def deriv(fn, xs):
    y = fn(xs)
    g, = torch.autograd.grad(y.sum(), xs, create_graph=False)
    return g.detach()

plt.figure(figsize=(6.5, 4.2))
for name, fn in [("ReLU", F.relu), ("Sigmoid", torch.sigmoid),
                 ("SiLU", F.silu), ("GELU", F.gelu)]:
    plt.plot(xs.detach().numpy(), deriv(fn, xs).numpy(), label=name, lw=2)
plt.axhline(0, lw=0.6, c="k"); plt.axvline(0, lw=0.6, c="k")
plt.title("Derivatives of activation functions")
plt.xlabel("x"); plt.ylabel("d activation / dx")
plt.legend(); plt.grid(alpha=0.3)
plt.tight_layout(); plt.show()
print("观察: ReLU 导数是 0/1 阶跃; SiLU/GELU 导数平滑且负区间可为负 -> 梯度更丰富")


观察: ReLU 导数是 0/1 阶跃; SiLU/GELU 导数平滑且负区间可为负 -> 梯度更丰富

Part C · 聚焦 SiLU
#

$$\mathrm{SiLU}(x) = x \cdot \sigma(x), \qquad \sigma(x) = \frac{1}{1+e^{-x}}$$

关键性质：

  1. 逐元素运算——对张量里每个数独立作用，形状完全不变（这是 run_silu 的类型注解 ... -> ... 在提醒你的）。
  2. 平滑——处处可导，没有 ReLU 的折角。
  3. 非单调——负区间先下降到约 $-0.278$（在 $x\approx-1.278$ 处）再回升，这个"小凹槽"让它比 ReLU 表达力更强。
  4. 当 $x$ 很大时 $\sigma(x)\to1$，SiLU 近似 $x$（像 ReLU 的正半轴）；当 $x$ 很小时 $\sigma(x)\to0$，SiLU $\to0$。

下面把 SiLU 拆成"输入 $x$“和"门 $\sigma(x)$“两部分看——你会发现 SiLU 本身就是一种"自门控”：用自己的 sigmoid 当门。

xs = torch.linspace(-6, 6, 400) # torch.linspace 用来生成一个等间隔的一维张量，基本形式是torch.linspace(start, end, steps)
gate = torch.sigmoid(xs)     # 门: 落在 (0,1)
out  = xs * gate             # 这就是 SiLU 的定义式所描述的行为

fig, ax = plt.subplots(1, 2, figsize=(10, 4))
ax[0].plot(xs.numpy(), xs.numpy(), "--", label="x (identity)")
ax[0].plot(xs.numpy(), gate.numpy(), label="gate = sigmoid(x)")
ax[0].set_title("SiLU = x * sigmoid(x): the two parts")
ax[0].legend(); ax[0].grid(alpha=0.3); ax[0].axhline(0, lw=0.6, c="k"); ax[0].axvline(0, lw=0.6, c="k")

ax[1].plot(xs.numpy(), out.numpy(), c="C3", lw=2, label="SiLU(x)")
ax[1].scatter([-1.278], [-0.278], c="k", zorder=5)
ax[1].annotate("min ~ -0.278", (-1.278, -0.278), textcoords="offset points", xytext=(30, -5))
ax[1].set_title("SiLU is smooth and non-monotonic")
ax[1].legend(); ax[1].grid(alpha=0.3); ax[1].axhline(0, lw=0.6, c="k"); ax[1].axvline(0, lw=0.6, c="k")
plt.tight_layout(); plt.show()
print("SiLU 用自己的 sigmoid(x) 当门 -> '自门控'; 这也是理解下面 SwiGLU 的桥梁")


SiLU 用自己的 sigmoid(x) 当门 -> '自门控'; 这也是理解下面 SwiGLU 的桥梁

def silu(x):
    # step 1: 逐元素算门 sigmoid(x) —— 用 torch.sigmoid，落在 (0,1)
    # step 2: 把门逐元素乘回输入 x，得到与 x 同形状的结果
    # return ...
    return x * torch.sigmoid(x)

Part D · 门控线性单元 (GLU) 的直觉
#

门控的核心思想：把信号分成两路，一路是"内容”，另一路经过一个 $[0,1]$ 的"门"，再把两路逐元素相乘。门接近 1 的地方内容通过，门接近 0 的地方内容被抑制——相当于让网络自己学会该让哪些信息流过。

下面用一个玩具信号演示：内容是一条正弦波，门是一个只在中间一段接近 1、两端接近 0 的窗。相乘后，只有"门打开"的区域信息被保留。这只是直觉演示，不是任何作业实现。

t = torch.linspace(0, 4 * np.pi, 300)
content = torch.sin(t)                              # 待调控的"内容"信号
raw = 6 * torch.sin(t / 4 - np.pi / 2)              # 一个原始打分
gate = torch.sigmoid(raw)                           # 压成 (0,1) 的"门"
gated = content * gate                              # 逐元素相乘 = 门控

fig, ax = plt.subplots(3, 1, figsize=(7.5, 5.5), sharex=True)
ax[0].plot(t.numpy(), content.numpy(), c="C0"); ax[0].set_title("content signal")
ax[1].plot(t.numpy(), gate.numpy(), c="C1"); ax[1].set_title("gate in (0,1)"); ax[1].set_ylim(-0.1, 1.1)
ax[2].plot(t.numpy(), gated.numpy(), c="C3"); ax[2].set_title("gated = content * gate")
for a_ in ax: a_.grid(alpha=0.3); a_.axhline(0, lw=0.6, c="k")
ax[2].set_xlabel("position")
plt.tight_layout(); plt.show()
print("门~1 处内容通过, 门~0 处内容被抑制 —— 网络借此学会'选择性放行'信息")


门~1 处内容通过, 门~0 处内容被抑制 —— 网络借此学会'选择性放行'信息

Part E · SwiGLU：SiLU 门控的 FFN
#

标准 Transformer FFN 是 “上投影 → 激活 → 下投影"两个权重。SwiGLU 把它改成门控版本，用三个权重：

$$\mathrm{SwiGLU}(x) = W_2\Big(\; \mathrm{SiLU}(W_1 x)\;\odot\;(W_3 x)\;\Big)$$

其中 $\odot$ 是逐元素相乘。直觉：

  • $x$ 先被两路上投影到 $d_{ff}$ 维：一路 $W_1 x$ 过 SiLU 当"激活/内容”，另一路 $W_3 x$ 当"门"。
  • 两路逐元素相乘（这就是 Part D 的门控），再由 $W_2$ 下投影回 $d_{model}$。

形状约定（来自 run_swiglu 的 docstring，务必对齐）：

权重 形状 作用
w1_weight (d_ff, d_model) 上投影（其结果过 SiLU）
w3_weight (d_ff, d_model) 上投影（当门）
w2_weight (d_model, d_ff) 下投影回 d_model

注意 w1 和 w3 形状完全一样——所以要想清楚哪一路过 SiLU、哪一路当门，别接反了。

E.2 $d_{ff}$ 怎么选？
#

真实模型里 SwiGLU 的 $d_{ff}$ 常取约 $\frac{8}{3}d_{model}$（因为 SwiGLU 多一个权重矩阵，为了让参数量和普通 FFN 的 $4 d_{model}$ 相当，就把内部维度按比例缩小），并对齐到某个整数倍（如调成 64 的整数倍）方便硬件。

但这只是初始化/配置时的经验值——在你的实现里，run_swiglu 会直接把 d_ff 作为参数传进来（本作业测试里 d_ff=128）。所以你的 SwiGLU 千万别把 d_ff 写死成 8/3*d_model，要用外部传入的值。下面只做个数值演示帮你理解这个经验公式。

def rounded_dff(d_model, multiple=64):
    raw = 8 / 3 * d_model
    return int(round(raw / multiple) * multiple)

print(f"{'d_model':>8} | {'8/3*d_model':>12} | {'对齐到64后':>10}")
for dm in [512, 768, 1024, 1600]:
    print(f"{dm:>8} | {8/3*dm:>12.1f} | {rounded_dff(dm):>10}")

print("你的实现必须使用传入的 d_ff, 不能写死成 8/3*d_model。")

E.3 ✏️ 你的任务：SwiGLU 引导骨架
#

from cs336_basics.linear import Linear

        #   注意: 用传入的 d_ff, 不要写死成 8/3*d_model
        #   self.w1 = ...   self.w2 = ...   self.w3 = ...
        self.w1 = Linear(d_model, d_ff)
        self.w3 = Linear(d_model, d_ff)
        self.w2 = Linear(d_ff, d_model)
        

    def forward(self, x):
        # step 2: 一路上投影 W1 x, 过 SiLU -> "内容/激活"    (形状 (..., d_ff))
        # step 3: 另一路上投影 W3 x -> "门"                  (形状 (..., d_ff))
        #   想清楚: 哪一路过 SiLU? 哪一路当门? (对照公式, 别接反)
        # step 4: 两路逐元素相乘 (门控)                       (形状 (..., d_ff))
        # step 5: 用 W2 下投影回 d_model                     (形状 (..., d_model))
        # return ...
        return self.w2(silu(self.w1(x)) * self.w3(x))

#

  4. 参数量核对：给定 d_model，分别算普通 FFN（2 个 d_model×4d_model 矩阵）和 SwiGLU（3 个含 8/3 d_model 的矩阵）的参数量，验证"约相当"这句话。

答案
#

  1. 本来是W2( SiLU(W1x) ⊙ (W3x) )，接反了就变成W2( SiLU(W3x) ⊙ (W1x) )，SiLU函数的作用域会变反，两个答案会不相等。原因是SiLU会非线形的改变输入，导致结果不同。
  2. 对于负数输入：
  • ReLU 的梯度恒为 0，神经元一旦长期处于负区间，就无法通过梯度更新，可能形成“死神经元”。
  • SiLU 在负区间通常仍有非零梯度，梯度还能继续反向传播，因此神经元仍有机会更新参数并恢复。
import torch
import torch.nn.functional as F

# 一批负数输入
x = torch.tensor([-5.0, -2.0, -1.0, -0.5], requires_grad=True)

# SiLU 的梯度
silu_output = F.silu(x)
silu_output.sum().backward()
silu_grad = x.grad.clone()

# 清空梯度
x.grad.zero_()

# ReLU 的梯度
relu_output = F.relu(x)
relu_output.sum().backward()
relu_grad = x.grad.clone()

print("输入：", x.detach())
print("SiLU 输出：", silu_output.detach())
print("SiLU 梯度：", silu_grad)
print("ReLU 输出：", relu_output.detach())
print("ReLU 梯度：", relu_grad)

输入： tensor([-5.0000, -2.0000, -1.0000, -0.5000])
SiLU 输出： tensor([-0.0335, -0.2384, -0.2689, -0.1888])
SiLU 梯度： tensor([-0.0265, -0.0908,  0.0723,  0.2600])
ReLU 输出： tensor([0., 0., 0., 0.])
ReLU 梯度： tensor([0., 0., 0., 0.])
  1. 对梯度回传的影响是：梯度会变小，甚至接近消失。因为 sigmoid 的导数是：sigmoid(x) * (1 - sigmoid(x))。 当 gate 接近 0 时：gate * (1 - gate) ≈ 0 当 gate 接近 1 时：gate * (1 - gate) ≈ 0 会让梯度更新速度很慢。
  2. 普通 FFN（2 个 d_model×4d_model 矩阵）：也就是 2 * d_model * 4d_model = 8 * d_model^2 SwiGLU（3 个含 d_ff = 8/3 d_model 的矩阵）：也就是 3 * 8/3 * d_model * d_model = 8 * d_model^2

小结
#

  • 没有非线性，深层网络会塌缩成单个线性层——激活是让深度有意义的前提（呼应第 01 章）。
  • ReLU 简单但有折角、负半轴梯度为 0；SiLU / GELU 平滑、非单调，梯度更丰富。
  • SiLU(x) = x·σ(x) 是逐元素运算，形状不变，本质是"自门控"。
  • 门控：一路当门（$[0,1]$）逐元素乘另一路内容，让网络学会选择性放行信息。
  • SwiGLU$=W_2(\mathrm{SiLU}(W_1x)\odot W_3x)$，三个权重；w1/w3 形状同为 (d_ff, d_model)，w2 为 (d_model, d_ff)；d_ff 用传入值，别写死。
